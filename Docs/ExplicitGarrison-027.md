# 0.2.7 明确驻扎指令

这是本项目主动补充的操作契约。G 热键、按钮布局和目标选择优先级不宣称是《帝国时代 III：决定版》的原始设置。

0.2.6 原生玩家对局中，村民右键受损城镇中心会优先收到修理命令。0.2.7 保留这一普通右键行为，另提供 G 热键和 GARRISON [G] 按钮：选中己方移动单位后进入驻扎目标模式，左键点击当前可见、己方、已完工且具有驻扎容量的建筑，提交现有 World.Issue 的 Garrison 命令。接收建筑受损不影响这条明确指令。同一点同时覆盖敌军与可用接收建筑时，驻扎模式优先选择接收建筑。

空地、敌方建筑、未完工建筑和无驻扎能力的目标会显示原因并保持目标模式；没有任何可用行动者导致命令拒绝时也保持模式。命令被接受后退出模式。容量没有在发令时预约，实际到达时仍由既有模拟检查；容量不足时保持既有“Garrison full”行为。本轮没有修改驻扎资格、容量、人口、城镇中心驻扎火力或建筑被毁后的释放规则。

G 再次按下、右键和 ESC 取消目标模式，不产生地面移动订单。A/攻击移动按钮切换到攻击移动；B/建筑菜单清理目标模式；停止和驻守清理当前目标模式。Shift 的排队状态取自对应的离散输入事件，传给统一命令接口。重新开始会清理模式和编队选择。驻扎模式下点击小地图只提示在世界视图选择建筑，不能把小地图地面点当作接收建筑。

常用单位按钮 DETAILS 与 GROUPS 仍固定在第二行的前两格。GARRISON 位于它们之后，避免新增按钮与 FOCUS/DETAILS 重叠。顶部指令栏持续显示驻扎目标状态，短暂事件提示消失后仍能识别当前模式。所有可移动单位显示按钮；实际资格仍由项目模拟规则决定。

PlayMode 测试使用真正的键盘、鼠标事件、UGUI 命中和现有命令接口，验证受损建筑明确驻扎、普通右键修理、无效目标、敌军遮挡、取消、Shift 队列、模式切换、重开、无行动者拒绝以及布局不重叠。通过一次接收并继续推进模拟的测试检查实际入驻，不能只以“订单已生成”代替驻扎完成。
