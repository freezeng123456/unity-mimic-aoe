# 0.2.0 群体通行修复与证据

本轮原断言要求 100、200、400 个初始互不重叠的步兵、骑兵和炮兵，从隔墙一侧通过唯一通道到达各自不同的编队目标；每个模拟 tick 检查单位半径不侵入障碍，240 模拟秒内每个单位距指定目标小于 1。另有 100 个同阵营混合单位双向通行测试。不是只数槽位或求两条静态路径。

初次 400 单位测试有 85 个未抵达。后续保留同一到达标准与时限，逐项诊断：

1. 局部避让按最终目标直线距离打分，错误惩罚朝通道行进的动作。现在使用下一路径点打分，预测不会超出即将到达的转角。
2. 新路线仍与寻路前的直线距离比较，正常绕路被判卡住。现在沿路径计算剩余距离，并在路径替换时重置进展基准。
3. 分数坐标取整可能选中被阻挡的图节点，平滑路径的首段未从真实起点验证，末段未保留真实目标。现在连接可达图节点并保留实际起终点。
4. 避让后原路径点可能被遮挡，或被已经到位的友军占据。现在检查当前可达性，重新寻路，并在下一段可见时允许跳过已不需要的转角。
5. 原卡住恢复只检查绕行点本身可站立，可能选到墙另一侧，把单位送回通道。现在局部恢复还要求整段直达可行。

边界：这是模拟通行验证；没有用它宣称 400 单位客户端帧率达标。地图桥梁表现、多阵营交战拥堵、建筑动态变化的全部组合、单位间短暂重叠上限和完整人工操作仍需各自验证。路径线段目前使用离散采样，不能宣称连续碰撞的数学保证。
