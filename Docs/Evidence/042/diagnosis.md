# 042 镜头与未探索区域操作

用户明确暂停迷雾问题排查，当前问题为镜头无法向外移动、无法命令单位走出视野。

## 初始证据

在0.2.18、GUID5e6bc4c120a745428cfac709cc960521、现有match432fd4b7762d4386bc90f7a108e35f32实际检查。当前局已包含用户操作，不能继续算041受控训练经验测试。恢复对局后，右边界内10个桌面点处左击并停留，镜头保持；改为2个桌面点后镜头向右移动，再ESC暂停于358.61267。F9原始配对画面另存本目录。实际窗口逻辑1280x720内容区，Unity渲染2560x1440。源码边缘阈值8渲染像素，约4桌面点；输入恰到右边界附近可以滚动，因此当前没有证据证明Retina坐标存在2倍错配。

地面右键、小地图右键的Move/AttackMove没有可见性限制，目标型攻击/采集等才检查实体可见性。需要真实输入回归核实。

## 实施契约

将8px固定边缘带改为窗口短边3%，最小16、最大64输入像素，四边对称。保留窗口外停止、失焦停止、暂停/模态停止和地图边界。对角线方向长度限制为1，避免对角移动更快。键盘方向键和中键拖动继续可用；不改变迷雾、导航或单位指令规则。HUD提供简短可见镜头/小地图提示。

先将既有边缘判定原样提取到可测试方法，再以更宽边缘的行为检查旧阈值失败；之后修改。最终必须检查Unity原生四边镜头、未探索点移动、小地图定位与暂停恢复。测试覆盖不等于完整对局完成。
