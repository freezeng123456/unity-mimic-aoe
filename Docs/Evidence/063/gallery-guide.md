# 0.6.0 曲河图集

10 张 2048×1400 原图。使用实际 World、WorldView、GameCamera 与 URP，在 Editor PlayMode 中拍摄。场景直接布置实体、明确揭示视野、关闭 AI；没有用图片生成器制作演示图。

| 文件 | 内容 |
|---|---|
| winding-01-landscape.png | 蜿蜒河谷、河宽变化、岸坡、双桥与开局城镇 |
| winding-02-harbor.png | 旋转岸仓与栈桥、厚船体、船员、捕鱼与尾流 |
| winding-03-bridge-underpass.png | 桥上陆军、桥下船只的高度分层 |
| winding-04-naval-combat.png | 正常攻击命令推进后的实际炮击与飞行弹丸 |
| tropical-01-landscape.png / tropical-02-harbor.png | 热带宽河湾、棕榈与港区近景 |
| tributaries-01-landscape.png / tributaries-02-harbor.png | 支流汇合、三桥与港区 |
| estuary-01-landscape.png / estuary-02-harbor.png | 北端宽河口、潮滩及港区 |

每张图旁的同名 JSON 记录 SHA-256、源码指纹、相机、实体、命令、渔获或伤害记录。共同来源清单为 source-inventory-water-063.json。捕鱼和战斗经正常公开命令与模拟推进；摆放实体和揭示视野属于受控夹具，不代表普通开局付费建造、原生人工整局、平衡或帧率验收。

原生 macOS 客户端、F9 截图、短时性能样本及构建 GUID 另在 Native 与发布 manifest 中记录。
