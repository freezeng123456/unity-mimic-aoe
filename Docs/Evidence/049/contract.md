# 049 单位移动与工作声音（P）

前轮为progress：0.2.24已封存，164/163测试、两个受控残局、两组正常回归、构建和分包完整性验证完成。阶段D尚未完成。本轮旧构建275项输入已经逐项核实一致。用户0.2.21游戏保留，不操作桌面或启动新版。

当前代码只有Gun/Cannon/Melee/Impact/Notice五类音，没有脚步、骑乘、轮子或采集施工声音。此次是明确未实现功能的补齐，不伪装成用户已报告且成功复现的特定声效故障；缺失回调直接由源码证实，因此无需虚构多个原因假说。另一个可复现问题：Muted仅阻止新事件，暂停中关声音后PauseAll(false)仍无条件UnPause旧声道。先冻结通过实际World指令/时间推进和GameController.Update的行为测试，旧版本应缺少活动反馈和声道静音，再修改。

模拟只新增每个村民最近一次实际工作记录（动作、目标、资源种类、模拟时间）；采集真正Credit正收入后、施工进入有效施工聚合后、修理实际付款并恢复生命后记录。不得从“订单已接受”推断工作，不能因等待工作位、未完工设施或缺钱修理产生工作音。规则费用/效率/伤害/经验/AI/事件日志不改变。记录不存进共享Rules。

表现层每个新的模拟时间只观察一次，移动依据真实position-previousPosition并排除传送式大位移，步声按已移动距离触发。工作只消费最新模拟时刻的实际工作记录，稀疏播放，不补播历史活动。仅屏幕内、当前可见、活着、未驻扎的单位有活动声；失去可见性/屏幕外不积累，暂停/静音/重开重置节奏，停止后不生成新活动声。只听到当前可见动作，不能靠声音探测雾后单位。

保持12个固定声道：8战斗、2活动、2战略提示，活动不抢占枪炮与通知；同类和活动总频率限流，不为每单位创建AudioSource。活动最大约每0.085真实秒一个新短音，使用实际模拟距离/时间安排资格，低帧率不补播积压音。活动声使用屏幕左右位置设置panStereo，仍为二维混音而非声学传播；战斗保持既有可见性、距离和类别语义。普通脚步1.4世界单位、蹄声2.2、轮声1.8；工作间隔0.8模拟秒。它们是本项目视听参数，不是AoE参考规则或精确足底接触动画。

原创短合成音：Footstep/Hoof/Wheel/Woodcut/Mine/Handling/Build，22050Hz单声道≤0.35秒；首尾0，有attack/release，有限样本及峰值限制；无新增第三方音频或依赖。关声音立即停止并mute所有声道，解除静音不恢复旧尾音；暂停恢复尊重静音。默认实时阴影继续关闭。

先运行旧红用例，再同文件绿；验证真实移动、收入、施工、修理、缺钱、停止、视野/屏幕边界、静音与重开。全量规则和场景回归，普通对局与0.2.24复用基线比较事件/经济结果以证明未改模拟结算；构建后输入和包哈希核对。声波检查和Unity自动测试不能代替耳听、实时混音、原生完整对局或最新400实体性能；未能做的原生检查明确待验收。
