This PR expands the original RTS prototype into a six-civilization river game and adds local replay plus two-human trusted LAN co-op. Britain, the Netherlands, France and the Ottomans join two original civilizations; curved river maps, ports, ship transport, neutral services, industrial production, team play, courses and an original campaign remain available.

The new 0.11 LAN mode lets a P1 host and P3 client use their own economies and armies against P2/P4 AI running only at the host. Both players ready their civilization/deck in a manually addressed lobby. Commands receive a real host acceptance or rejection, and the client waits for the corresponding replicated revision before showing completion. Stable network production IDs cancel the clicked task despite queue index changes. Full/incremental replication, bounded transport queues, request/result deduplication and reconnect grace retain the host authority. Escape/focus loss opens a local menu; shared pause/resume remains a host-ordered action, including resume while the ally is temporarily offline.
