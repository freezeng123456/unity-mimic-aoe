本目录归档一次真正从普通开局运行到自然终局的原生客户端局：法国对奥斯曼、Standard AI、`winding`、seed `314159`、I–V 上限。双方按规则从 I 时代和 `300 F / 300 W / 100 C` 起步；运行使用 **Autoplay 双 AI、16×固定步模拟**，不属于人工普通速度对局，也没有额外 age/XP/资源/HP 或直接实体授予。原始开局事件、运行收据和客户端日志未出现 benchmark、cheat、controlled/grant 标记。

版本 `0.7.0`，GUID `48cbcf92c92f409c945f83eeb9b8d500`，match `dbd741b540e54a81a0822f068d5a6446`。来源指纹、最终测试与原生构建的绑定见 [客户端回执](../client-build.json)；完整文件核对和独立事件复核见 [hash-verification.json](hash-verification.json)。本次仅归档既有记录，没有启动客户端、改变世界或压缩材料。

## 自然胜利与原始事件

[run.json](run.json) 指向本场终局报告、全事件与两对 F9。[终局报告](20261004-203833-422-dbd741b540e54a81a0822f068d5a6446-match_finished.json) 与 [完整事件](20261004-203833-422-dbd741b540e54a81a0822f068d5a6446-match_finished-events.jsonl) 一致：法国在 **1047.691284180 模拟秒**获胜，原因是全部对手单位和建筑被消灭，终局时代 **4 / 2**，船运 **10 / 5**。

完整 41,227 条事件的数量和逐类计数与 [event-summary.json](event-summary.json) 完全相符；其 13 条 selectedEvents 均在原始 JSONL 中逐字段唯一匹配。终局事件在第 41,197 行，随后是同一终局时间的收入桶清空记录，均保留原样。I 时代六工人、城镇及资源布局由正常初始化产生；自然晋级分别记录法国 II=213.703842164、III=627.293884277、IV=944.816345215 秒，奥斯曼 II=296.508880615 秒。

根节点本轮客户端执行观察为退出码 0；原 `run.json` 未单独保存进程退出码，归档将这个根节点观察与文件本身的独立核对区分。日志记录了 quit 报告和输入线程退出；quit 报告不在本次输入文件集合内，因此没有补造归档。

## 资金核对范围

147 条 Payment 事件均携带真实 balanceBefore/After/actualDelta；逐条算术完全相符、余额非负，累计实际支出与终局 spent 三资源逐项一致。食物贸易收入 600 也与原始 TradeDelivery 一致。

但是 `initial + gathered + passiveIncome + tradeIncome + refunded - spent` 与终局 resources 不逐字节相等。资源残差（实际减上述重建，F/W/C）为法国 `+5.096862793 / +3.309387207 / +0.691070557`，奥斯曼 `+2.744262695 / -2.417709351 / -0.130889893`。源码收入和统计各自逐 tick 累加 float，原始 Gather 又按源聚合请求量，没有收入事务的 balanceBefore/After；不同累加舍入是与当前实现相符的解释，但现有记录不足以严密重建全局余额。故此归档**不将全资金守恒标记为 PASS**，不把差值解释成已证实的额外授予。
