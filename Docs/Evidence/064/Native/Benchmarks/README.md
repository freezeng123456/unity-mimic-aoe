# 0.7.0 最终原生压力样本

此目录只归档 `Native/Benchmarks` 根目录的最终 **200/400 陆军加 12 船** 两组报告、4 对 F9、焦点说明和清洗日志；本地 `Pilots` 未复制。元数据、文件哈希和报告/F9 对应关系已独立核验，结果属于高血量、直接生成军队的移动/战斗夹具。

两组都是**约 90 秒总 active 时间，其中前 10 秒预热，统计约 80 秒**；各有 800 个实际测量步。200 组 P95/P99 为 17.063089/17.582590 ms；400 组为 32.546711/33.583000 ms，后者仍有 13 帧超过 50 ms、1 帧超过 100 ms。不能据此宣称全负载稳定 60 FPS、正常战争体验或长期无泄漏。

## 身份与条件

- 应用 0.7.0，Unity 6000.6.3f1，macOS arm64 Development / Mono；GUID `48cbcf92c92f409c945f83eeb9b8d500`。
- Runtime commit `5cce74ccf7222133af9bad633923f452b100bfb2`，源码指纹 `8342b85bf835fd48d5c4dfc8f612ed64770fc5b7d026d96c4f539caaa96d79b0`，与 [客户端回执](../client-build.json) 和 [最终测试](../../Tests/README.md) 一致。
- Apple M3 Pro CPU/GPU，系统内存报告 `memoryMb=36864`，1600×1000，Winding，seed 314159，orthographic size 26，60 fps cap、vSync off。
- 夹具直接生成混合陆兵与每组 12 艘船，反复发送移动/交战命令，并将运行时生命提高到 1,000,000 以保留负载。普通经济、付费征兵、人口上限和自然终局不是该样本的验收对象。
- 200 match：`ba15782dd5d1411b912d676094557c9f`；400 match：`3df7ee91fe5d47c9bf64cfbf83037c21`。初始/结束活体总数分别保持 212/212 与 412/412。

[200-focus.json](200-focus.json) 和 [400-focus.json](400-focus.json) 记录操作者在 10 秒预热内将窗口置于前台，并表示测量期间没有执行改变焦点的 UI 调用。实际 F9 在预热期 world time 约 3 秒为 focused=true，报告保存和结束 F9 也为 true。**没有连续焦点记录**，因此这只能证明这些采样时点的前台状态，不能升级为全程已仪器化验证的 focused 窗口。
