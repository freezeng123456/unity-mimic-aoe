# Frontier Reckoning 0.9.0

独立原创即时战略游戏。将本目录完整解压到本地，启动 `Frontier Reckoning.app`。适用 Apple Silicon macOS；此包是 Unity 6000.6.3f1 Development/Mono 构建，未签名公证，未验证 Intel Mac。

本批新增：本地2对2与4方混战（你控制slot1，其余AI）、共享盟友视野和团队胜负；七课中文操作教学；三章原创河谷战役逐章解锁；独立课程进度；音效/音乐/环境音分项音量、界面缩放、高对比小地图、友敌图案、事件文字与20项按键改绑。

开始：可先进入 GUIDED LESSONS 的「选取与移动」，单击己方探路者，右键金色目标并实际抵达。完整玩家指南在源码包 `Docs/Player-Guide-066.md`。菜单 ROSTER 顶部按钮循环1v1、2v2、4方混战；MAP按钮选择九张地图。你拥有独立经济与控制权，盟友共享视野。

默认右键移动/攻击目标；A攻击移动、S停止、J固守、G驻军、R修复、H家乡、B建造、V或句点空闲工人。SETTINGS→HOTKEYS可改绑；本测试曾改为Q，但交付不含测试偏好或个人存档，初次启动使用默认值。Escape暂停，F8性能采样，F9真实PNG/JSON截图；保留F8-F10、数字和修饰键。

通过GUI保存到槽1–3；存档严格匹配版本。现有0.7/0.8存档保持原文件，0.9会提示版本不兼容。设置、账号完成记录与对局存档独立保存在 macOS Application Support/Frontier Workshop/Frontier Reckoning 下。测试使用的槽3、设置和账号记录已受控恢复为原状态。

完整回归1062/1062（710 EditMode+352 PlayMode），源码指纹 66cf7cc57e080eb40cfdf98310ee26affd93d690745dde2b457e8fb3eb0ee1ee，GUID 1969c7ee14f944879510f4ca0d0f241d。另有真实原生代表性操作验收和截图；这不证明所有课程原生通关或新的400单位性能指标。

包含六文明、五时代、家乡卡组、曲河/支流/河口、港区/水战、贸易与探索等已有机制。尚未提供联网/回放/关卡编辑器、官方全部国家和战役、角色配音；建模和战役规模仍需扩展。资产许可见 Licenses；Noto CJK字体按OFL分发。
