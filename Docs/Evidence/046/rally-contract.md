# 046 资源耗尽后的生产集结补全（P）

原生0.2.21开局中资源箱耗尽后，后续TC村民到旧坐标闲置。Resource-Rally-029.md第5项和ResourceRallyTests表明这属于早期主动简化，不是采集账本漏记。本轮改变该P选择；AoE3:DE精确目标失效规则仍为U，未把本项目补全称原作规则。

SetRally在接受可见资源时保存ResourceKind；普通地面集结清除。每次真实生产出生或主动驻扎释放仍先检查原ID的可采性；原ID不可采且原记录集结点当前Visible时，在该点18世界单位内选择最近可见、同ResourceKind、合法可采目标。全程使用GatherableResource和World.Issue，不直接加资源、不缩短生产。只含军事单位的组不触发替代查找；军事单位仍按已记录坐标分散移动。

未探索/已探索但不可见的原点不发起替代查找。隐藏资源、敌方农田、未完成或耗尽资源、不同资源种类不作为替代。无候选则保留Move回退。替代查找每次按出生组进行，不做全单位每帧扫描。保持原集结旗作为玩家指定区域；新工人可在该区域内分配不同资源点，不强改已出生单位或军事集结。实际新目标以RallyRetargeted和RallyAssigned事件记录，HUD说明为在资源旗附近采集指定类型。

先在未修改运行时上运行新增实际付费训练/小箱真实耗尽/替代采集账本回归，记录红例，然后实现并重跑同一文件；原ResourceRallyTests及相关经济/驻扎/生命周期测试继续覆盖。0.2.21原生进行中的局保持原版，后台改源码不会替换它。新版未经原生测试不会称原生已验收。
