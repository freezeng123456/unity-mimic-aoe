# River 原生玩家操作参考（静态，不是对局证据）

依据冻结的 0.2.31 Rules/模拟/HUD源码及本目录[总预算](README.md)。只读公共规则；不读取正在进行的敌方状态。不保证获胜，不增加验收门槛，也不修改费用、AI、源代码或客户端。操作仍是普通菜单、可暂停规划、恢复后下令、1倍速；所有时间是队列/施工下界，资源与战况以当局HUD为准。

## 可持续开局

River 库存是 **100F/300W/400C**，另有真实 **300F/300W箱**，6工与450HP探索者。食物箱收完转可见鹿；木箱需要工人实际采。付费工100C/20s，House100W/25s只加10人口，不赠工。先正常训练约4工，达到约10工；达到800F时避免继续堆TC队列，支付II后等90s真实完成。第一House及木箱采集可由1–2工并行，其他工逐渐分到至少两个鹿节点，单节点最多8个有效工。

探索者先处理可见木宝藏，再处理可见XP宝藏。这能帮助首票：开局600箱实际采集约60XP，4工实际训练20XP，House完工20XP，两守卫击杀16XP，XP宝藏100XP，合约**216XP**（未计鹿木等正常采集）。这些动作全部完成后的合计不是首票的保证时刻；150XP得到第一机会后，River Coin卡35s运来250C箱，需工人实际收完。没有Coast的I New Settlers卡。初始400C付4工以后是0C，250C船箱全部采完后付5Musk125C仅余125C，可再买1工并剩25C；若拿250C先买2工仅余50C，会缺75C火枪费用，必须另采矿。首防之前先留125C给Musk，不把同一箱同时算给工人与军队。

II先Barracks、首批5Pike，随后5Musk并保持TC射程内的阵线。两批合675F/200W/125C，军营另200W；Pike22s、Musk26s串行。River Economy25在II只有2Hussar军事船，**没有3Pike/3Musk卡**。首House100W+Barracks200W+5Pike200W+首Bank350W累计**850W**，开局木箱全部收完才有600W；即使75W宝藏也真正采完，仍须再得**175W**，之后每个额外House另加100W。不要从600W开局直接连续支付这四项。

可执行的采木顺序是：I先收300W箱及有条件时的75W宝藏，II研究90s期间约4工采**安全、可见树干**，其余约6工采鹿。4木工理想2W/s，175W需要87.5s；一旦这些工转施工、走路或驻军，时间相应延长。因此在II完工时先确认至少400W供Barracks+5Pike，军营建好付款后再看是否真剩350W，够才建首银行。没有采75W宝藏时缺250W，4木工需125s；少1木工或增加房屋也重新看库存，不照90s推断木已足。暂缓早Market/Foraging与TradePost，避免它们先花掉防军木。

II取得下一张**真实船运票**后，若木缺口拖住首银行/住房，优先600W卡。35s到港，4工采600W箱理想再需25s，2工需50s；看实际库存增长，不能把“已发船”当支付余额。随后按当下缺口选择3Settler、600F或600C，不预定三张都在II可用。木已足而粮缺，则600F能加速银行与III；币少先采矿/币船，不能把银行建好前的收入计入付款。资源箱采集结束将工人回原采集，不留Idle。

粮食也要逐笔预留。II完工若经济Governor200F箱已采完，5Pike300F+5Musk375F共675F，奖励只覆盖200F，还需当时存粮或新采475F；首银行另350F。以开局400F和II奖励200F均实收、没有粮船为例，付II800F+两批兵675F+首Bank350F，共1825F，累计还须**1225F正常采集**；不能用800F时代款再付军队。6鹿工理想5.04F/s，在II的90s约453.6F，加已采200F奖励仅653.6F，仍比两批兵缺21.4F，尚未预算银行；建造/移动还会进一步降粮产。先Pike守骑兵，再集够375F125C训练Musk，银行在兵款之外有350F350W余量才付。

在资源足够且首防不会被挤掉时，用2–4工建第一银行（350F/350W，70s基础，4工约28s）。第二银行应在首批防军、住房及粮木已有余量后补；第二座再需350F350W，不能从首座的余额复用。两银行加首防及II累计2175F/1200W，不含额外房屋/补损；无粮船时扣开局400F+II奖励200F后须累计采1575F。工人向约24扩张，3Settler船实际到港可省300C及60s TC队列；总人口连军队接近上限前建下一House。

两银行完成后5C/s恰够100C/20s持续买工；其余产币才是时代余款。可用正常近矿/600C船填缺口，接近1200F/1000C时停新工付款，支付III、等待110s完成。时代完成各奖100XP；不是随时代递增200/300XP。I付费工+II/III占用同一TC队列，24工若含6初始+3船工+15付费工，光队列下界就是300+90+110=500s；提前10–12工进II与II后补工都是取舍，不能承诺固定III时刻。

## III后防守与高时代

III先保现存前排，再建Foundry、Stable。付费Carabineer可以SINGLE40F/70C/28s满足路线，也可实际BATCH5花200F/350C/28s加强阵线；它只有1人口，速度7、射程12，对重骑兵×3，145HP。Pike用于挡近战骑兵，Carabineer/Musk处理可见骑兵或炮。Economy25确有III 6Carabineer、6Pike、5Musk、1Cannon；都要真实票、35s串行、人口和出生空间，不能默认同时到账。

Foundry300W/55s，4工约22s。正常GUI两炮必须两次SINGLE，分别100W/250C/45s，串行约90s；一炮也能证明付费生产，但真正攻城要保护。Cannon220HP、70基础攻击、对步兵最高×2、建筑用130 siege，射程4–20、部署2s、移速2.5。选择车架中心/窄框并看HUD，前排Pike离炮约5–8米，炮另选，先共同移动到实际侦察出的建筑附近，再点击当前可见敌建筑；不要让炮穿过骑兵线。Cannon也不能直接打视野之外的建筑。

III四银行合10C/s；IV Ledger Dispatch真正到港后每银行3.125C/s，四座12.5C/s。Bank Charter只加1银行槽，不免费造银行；第五座另350F/350W，五座在Ledger后15.625C/s。只要资源可持续，四座即可计划高时代；不要为第五座挤掉防守或V付款。正常科技菜单中的Bank Ledgers有Bank Charter前置，Ledger Dispatch是一张真实IV科技船，由正常船运直接应用；以GUI卡牌是否可用及到港为准。

为了尽快进V，首防已有5Pike+5Musk时，III特色兵先付**1Carabineer**，炮先付**1Cannon**；实际出生后即满足各自付费路线，之后补到多少由可见战况决定。已有票可用6Carabineer/6Pike等补线，不能拿船兵替代付费出生。Barracks完成Veteran以后新增Musk取证也用SINGLE75F25C26s即可；不必为同属性证据再付5人批次，或无缺口时强做Guard/Imperial链。

III的1000W卡适合优先补两座银行700W+Foundry300W；真实III经济奖励200W可付Stable200W。这个例子已经花掉整张木卡和奖励，**两Farm600W、炮100W、住房、Market/Foraging/Crop375W、TradePost/Cargo400W都还要别的木来源**。保留约8木工持续采集，先按人口与防守补缺，再在III储IV期间完成两Farm和必要研究；贸易可与年龄队列并行，但不能花掉近敌炮/住房/维修的应急木。票少时先军事保采集，其次木/粮实际缺口，第五银行和Bank Charter暂后。

预留两Farm600W，完工后各8粮工。34工持续防守示例为10TC驻工+16粮+8木；若抽2工维修，真实采集人数再减2。Market100W/30s，Foraging75W/30s使Food+10%，III Crop200W/150C/50s须Foraging，再+20%；Farm .5→.55→.65F/工/s，16工最后624F/min。近端鹿浆果9000F加开局400F只够8000F时代与1400F四银行，军事/研究/补损要额外船粮、可见安全远鹿或Farm。剩4000F的V阶段，16升级Farm理想约385s，不能用几十秒等待假定完成。

IV付款2000F/1200C、130s；V4000F/4000C、160s。III付费炮已经成立后，IV军事Governor实际奖励2Cannon可帮助守线；经济Governor是600W/400C箱。两种都是正常选择，依当前缺口决定，不能提前消费奖励。V经济Governor1000F/1000W/1000C在完成V后才可用于最终补军。

有危险时短暂10工驻TC，清掉可见近敌后回采集。超过10工不加TC攻击；10工基础90/3s、射程16，不能自动清理射程外炮。两工维修36HP/s，3500HP TC持续受损时约154W/min；木库存不足要减少维修并恢复木工。面对可见敌炮，Pike先防骑兵，Musk/Carabineer主动攻击炮，再撤回Hold；等炮自行走进TC会让建筑先受损。军队不足时优先补军，不把银行收入同时算给V与连续补兵。

## 付费科技的同单位与新单位证据

选择一个现存己方Musk，J守安全后方；保存升级前单选HUD/DETAILS F9，记录选中单位身份。III Barracks付费Veteran Musketeer100F/100C/40s；军营已有训练会先执行，付款不是完成。完成后重新选择**同一个**单位，保存HUD/DETAILS F9：满血200/200、ATK24应成为240/240、ATK28.8（主HUD四舍五入29、DETAILS显示28.8）。受伤单位按原生命比例增加，不能要求当前HP必240。

随后普通付费训练新Musk，出生后单选其HUD/DETAILS F9，确认新单位同样MaxHP240、ATK28.8，并让最终原生事件绑定研究前后与出生身份。F9 JSON既没有单位HP/ATK，也没有单选单位ID字段，不补造字段。身份可用每次单选后J的原生`Command Hold ×1`之actor ID绑定，再保存对应HUD/DETAILS F9；已有inputtrace还可用`FRONTIER_UI context entity`与截图request/captureFrame核对。升级前先由真实GROUPS→SAVE保存旧Musk，完成后召回活着的同一人、J与截图；新增Musk则绑定付款→Spawn→单选J。只这一个有意义的付费升级已可示范现存/新生应用；Guard/Imperial并非额外强制要求，若正常继续升级，其增量按加法叠加（1+.2+.3+.5）。

## 两宝藏与两贸易收入模式

木宝藏公开布点(40,30)无守卫，探索者在真正可见后右键Claim，靠近1.5、持续3s。它生成75W箱，不直接加库存；派己方工人实际收取，保留Claim与采箱证据。XP宝藏公开布点(47,40)有两85HP守卫，探索者14ATK/2s每守卫需7击；450HP通常足以应对两守卫的8ATK/2.2s，但要查看真实生命/其他敌人并逐个攻击。两守卫确实死亡后右键宝藏Claim3s得到100XP。布点只用于静态导航规划，操作时不得对不可见对象下定向攻击/Claim。

贸易站只能在真正可见且空的socket建造。靠己方的公开socket(44,81)可由探索者先沿己方侧侦察；工人需真实行走并安全施工。TradePost200W/60s，4工约24s；完成后默认XP，每次真实商队访问40XP（Cargo后50）。先留XP模式等**至少一次实际收入**，再付Cargo Ledgers200W/150C/45s，科技完成后选择Food/Wood/Coin之一、等至少一次实际访问入账。Food75、Wood62.5、Coin50直接入库，不是箱；此时XP+一种资源已是两种收入模式，不必额外全部手动切换。

商队速度4，公开路线单程约98.65米、往返约49.3s；靠己方socket的两次访问间隔交替约36.3s/13s，而不是固定每25秒。因此单次45s研究结束并不证明新模式已经收入，要看实际库存/通知并让最终TradeDelivery事件审核。只有占位完整且活着的Post有收入；原自动回归已检查毁坏/重建边界，不新增全手动验收。

## 尽快完成V与整局的付款顺序

先完成B再开C，菜单明确River、Easy、capV、Economy25，保存本次菜单F9与普通开局F9。对手可Coast或River，不要求对手到V。下表是状态触发顺序，不承诺模拟时刻：

| 状态 | 下一步与必须看见的结果 |
|---|---|
| I正常开局 | 开始真实采箱/鹿，付费工出生，完成可见木与XP宝藏；保125C火枪款，4木工在II研究期间补175W缺口。 |
| II已完成 | 军营→5Pike→5Musk实际出生，Move/J在TC附近分前后排；有独立350F350W才首Bank，防守稳定再第二Bank并持续正常出工。 |
| II准备III | 约20–24实存工、真军队守住采集点后，停止新的工人付款和非必要研究，把1200F1000C独立留给III。木/粮/币船依真实票与缺口，先实收再下单。 |
| III已完成 | 1付费Carabineer、1付费Cannon先出生；Veteran旧/新Musk取证；银行向4座、工人向约34扩张，600W两Farm及时完工。普通船兵补Pike与射击线，军队少时先恢复阵线。 |
| III准备IV | 资源实际到2000F1200C立即付款，130s升级中继续采集、修建剩余Farm/Market与安全贸易站；可以补兵，但不能预花未到奖励。贸易默认XP实际访问一次，再Cargo完成后改Food/Wood/Coin并收一次。 |
| IV已完成 | 必要时用军事Governor真到2炮补防；若经济Governor则600W400C箱实际采。Ledger Dispatch有真票才发。约34工够持续经济后停止无限买工，单独攒4000F4000C；先保阵线和粮木工，只有实际损失/可见压力才继续军费。 |
| V付款与完成 | 4000F4000C真正支付、160s队列真正完成，保存AgeV F9；不要把付款或AI的V替代己方完成。升级中继续补军/守家，可把后续资源投入已有军队；V完成后的经济奖励才供最后进攻。 |
| 最终攻城与结算 | 侦察实际可见敌建筑，Pike护炮、炮在4–20射程部署，取得实际命中建筑；炮击后继续普通作战直到一方单位/建筑自然全灭，结算界面先F9，保留原生Report/events再回菜单。 |

四Bank无Ledger为600C/min，暂停购工及无军费时4000C约400s；四Bank有Ledger为750C/min，约320s。16升级Farm4000F约384.6s，故V储备通常粮食更慢，正常1000F/1400F粮卡实际采入可缩短缺口；这些是零起点、无支出、无行走/受袭的下界。34工中10人长期驻TC时已经只有24人在采集，不再扣一次；抽采集工施工/维修要另扣。安全时释放驻军能提高采集，但应在可见敌波已清掉、军队能护工时做。AgeIV的130s队列可在此期间积累大量V储备，别等IV完成才重启粮务。

炮兵对实际敌建筑的伤害可在III/IV取得并保存阶段F9，随后回防积累V；无需等V才第一次试炮。V完成前避免把对手所有剩余实体清光而提前结算。正常玩家可以守住已取得的阵地再推进，不用删除己方单位、认输、加速、隐藏敌坐标或免费资源延长/替代路线。获胜不是严格审核额外前提，完整必要事件齐全后的自然败局也保留如实审核。

## C原定范围与最终核对

[原合同C](../../../Development-Contract.md)是第二文明I–V、科技/特色单位/银行差异、贸易/宝藏、攻城及AI的原生整局。现有[river-v严格审核](../verify_player.py)继承B的真实采集、付费工/军事/炮、船运到达、敌建筑炮兵伤害，追加己方IV/V实际完成、付费Bank完工和真实被动币、付费Carabineer出生、付费研究完成、宝藏Claim、付费贸易站完工、实际XP贸易、合法资源模式和实际资源交付；同时要求普通开局、1x、autoplay=false、同版同match菜单证据、自然全灭且无Resign。

4/5银行、24/34工、2付费炮、全部军事卡、Guard/Imperial链、全部4贸易模式或3宝藏，并非原退出条件。这里选两宝藏是既定普通路线中资源箱与守卫/XP的展示，选择XP+一种资源足以展示贸易切换；科技同单位与新生单位的实际HUD/DETAILS另补视觉证据，审核脚本本身不证明属性画面。末局Report有支付/出生/ResearchComplete/Technology、TreasureClaimed、TradeDelivery与伤害身份，F9截图保留具体操作画面，二者不能互相替代。

## 原生操作边界

T/M/F/数字可换镜头，操作后重新读截图坐标；M只是轮选一个军事单位（含探索者）。单击与框选都以单位世界位置加Y=1的投影为中心，单击半径为`max(13, Screen.height / orthographicSize * .35)`像素，不按帽顶、脚尖或固定米数选人。Sky实际框选参数为`{app, from_x, from_y, to_x, to_y}`；fresh截图重取子集，拖后看HUD数量，建造/攻击/驻军目标模式未取消时左拖不会进行正常框选。Sky的super+数字在此前B5没有实际SaveGroup证据；用游戏GROUPS→SAVE槽并看到通知，未确认前直接框选/HUD下令。G是显式驻军目标模式，普通右键受伤己方建筑优先Repair，没有R维修热键。每次恢复、动作与收尾暂停同一调用，Escape可能先关H/B/科技/目标模式，再次Escape才暂停；必须读到MATCH PAUSED。自然结束先在DEFEAT/VICTORY保存F9，再回菜单；Ended时Escape会回菜单。
