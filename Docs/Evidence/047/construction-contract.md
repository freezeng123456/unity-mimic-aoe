# 047 施工与经济恢复合同（P）

当前正常0.2.22 Coast镜像局2180.576秒自然结束（V/IV），查出33条Gather命令在目标Farm/Coin Estate完工前发出。已有统一GatherableResource检查Complete，而AiWorkforce重复筛选遗漏该条件，Economy.Gather对未完工目标不采集。这是已定位的守卫条件缺口，不再展开无关的通用假设列表；先用真实付费建造+资源候选的冻结用例复现。

AI资源候选统一使用World.GatherableResource。未完工经济设施既不进入采集列表，也不作为当前可用的持续采集率来源；完工后下一次正常决策可用。不改变玩家Gather命令语义、产出、建筑时间、战斗或迷雾规则。

补齐无人施工地基恢复：每次AI决策至多给一座存活、己方、未完工且当前位置可见、周边没有已观察军事威胁的地基补派一名真实工人。优先最早的既有地基；原有非驻扎工人的队列中已包含该建筑Build指令时，不重复派工。候选仅空闲或只有一个Gather指令的非驻扎工人，不打断建设、撤退、修理和排队。选择距地基最近者，发送Order/Build指向原ID。不得CommandKind.Build新放地基、重复付款或直接增加施工进度。成功后发AIConstructionResumed事件。已完成建筑不派施工；驻扎不视作死亡，既有总人口与村民目标不改。

这个恢复策略是项目P决策，不是原作官方AI规则。安全判断沿用已有可见军事威胁范围max(12, range+4)，排除探险家；不查询雾后敌人。玩家正在运行的0.2.21不动。先冻结5项实际调用测试，在旧代码验证缺口，再修改并回归，最后按相同配置重跑正常长局观察新副作用，不能以单局胜负证明平衡或完整阶段D。
