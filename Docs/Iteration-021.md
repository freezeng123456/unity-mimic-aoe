# 0.2.1 迭代：陆图探索与贸易

完整目标继续为阶段A–D；本版本仍是阶段C开发检查点。0.1.3压缩包和0.2.0三次原生自动局保持历史证据，不能代替本版本人工完整对局。

## 进入当前代码的联动

- 原创探险家右键宝藏、守卫战斗、3秒收集、守卫清空验证与争抢一次结算。资源奖励为实际箱子，需要村民采集，经验奖励进入船运机制。
- 3个贸易站点与双向商队；普通村民支付、施工、占地、取消、摧毁和重建。只有完成站点且商队实际抵达路标才交付；默认XP，时代II付费货运账册研究后可选择资源。
- 8名中立守卫、6个宝藏、3个站点，全部通过既有迷雾与实体输入；商队视图按可见性隐藏，路线放在迷雾表面下。
- AI从可见目标选择宝藏/守卫并调用普通攻击/收集命令；可见空站点投资和贸易模式同样走玩家指令。仍未证实贸易争夺平衡或成熟AI。
- 对局报告增加build GUID、时代上限、现有资源/退款、时代历史、宝藏数、守卫击杀数和独立贸易收入，便于区分不同构建与真实来源。

精确数字是项目P设定，见 Implemented-Numbers-021.md；官方参考、未知项与实现合同见 Reference-Trade-Treasures.md 和 Landmarks-Implementation.md。
