# 陆图探索与贸易实现合同（开发中）

依据 Reference-Trade-Treasures.md 的 V/U 边界实现，以下所有精确值均为项目 P 参数。此合同先于运行时代码建立，不能视为原作数据或已完成验收。

- 固定双向商道经过3个站点；中立商队以4米/秒从一个路标走到下一路标，抵达端点后返程。贸易站仅在空站点建造，200木、60秒、1600HP、4×4占地。完工且存活的站点在商队抵达对应路标时获得40XP；暂停不推进路线，未完工、被摧毁或空站点没有收入。路线无贸易垄断胜利，商队目前不可攻击，不承诺原作的车速、路线共享升级或运输规则。
- 时代II的货运账册科技：200木150币、45秒，当前玩家贸易站解锁食物/木材/钱币模式并使每次交付乘1.25；基础交付60食物/50木材/40钱币。默认经验模式保留。收入由实际商队抵达事件记录，独立于村民采集和银行收益。
- 6个对称宝藏：每侧75木无守卫、100XP双守卫、150币双守卫。资源奖励生成真实资源箱，需要村民采集；探险家在清空绑定守卫后靠近并持续收集3秒。资源箱落点被阻塞时等待；中断重新累计，领取后移除且永不重复发奖。奖励归完成收集者，不是最后击杀者。
- 中立守卫：85HP、近战8、2.2秒间隔、3米/秒、9米视野、8击杀XP、营地10米追击范围；己方空闲单位只在4米内自动响应守卫，显式攻击/攻击移动可主动接战，不占玩家人口，绑定宝藏不重生。玩家与AI共用战斗结算；守卫不会得到玩家全图信息。探险家仍为普通可死亡单位，原作英雄倒地/赎回尚未实现。
- 站点、宝藏、守卫与商队显示遵守迷雾。AI只选择当前可见宝藏/守卫/站点；通过普通采集、攻击、建造、研究、模式命令操作。路线线条位于迷雾层之下，不从地形显示泄露未探索地标。

验收必须覆盖守卫未死不能领取、多人争抢一次结算、中断/暂停/重开、隐藏目标拒绝、资源箱实际采集、站点扣款/占用/取消/摧毁/重建、商队经过前后真实收入和模式升级幂等；同时需要原生玩家操作、画面和真实整局。原生验收通过前保持阶段C进行中。
