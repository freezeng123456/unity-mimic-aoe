# Navigation Revision 014

本轮针对窄口、动态建筑阻挡和群体移动进行有界修订。路径查询继续使用带访问标记复用数组和二叉堆的 8 向 A*，对角移动要求两个正交邻格均可通行；动态阻挡变化通过 `Version` 使移动实体重新规划。移动层使用路径目标分散、邻近单位分离向量、候选转向和卡住后重规划，避免把整群单位瞬移到同一点。

项目主动偏离：当前无全局水体/不可通行地形数据，窄沟与桥口以动态网格阻挡表达；没有宣称 100/200/400 单位已通过 Unity 实机性能或完整对局验证。新增 EditMode 压力边界覆盖 100 个编队槽位、双向窄口路径及移除大型阻挡后恢复通行。400 单位压力仍待 Unity 运行时测量，需记录帧时间、GC 与寻路耗时后再决定进一步优化。
