# 0.2.7 建筑与资源点击契约

这是本项目的输入与表现设计，未声称其几何算法来自参考游戏。0.2.6 原生实操中，树冠、军营屋顶等可见部分可能点击落空，只有地面中心或建筑基座容易命中。0.2.7 在保留地面占地判断的同时，加入由原创模型 Renderer 合并得到的世界空间轴对齐包围盒，相机射线命中该包围盒即可产生候选。

包围盒是可选体积的近似，会包含模型各部分之间的少量空隙；它不是逐三角形碰撞，也没有把树冠、旗帜或屋顶加入导航障碍。建筑地面占地仍由规则中的 width/depth 定义，资源采集仍针对真实资源实体 ID 和采集位置。选择圈表示地面选择提示，不宣称完整描出高处模型边缘。

只对建筑和资源缓存此体积：模型首次显示、对象池复用和施工缩放变化时读取 Renderer；根节点移动时更新缓存中心。单位维持现有投影半径判断，不扫描其动画 Renderer。选择圈、生命条和临时效果在模型层级之外，不进入可点击包围盒。当前建筑和资源没有动态旋转动画；以后增加此类动画时必须扩展缓存失效条件并增加回归测试。

战争迷雾、存活、驻扎和贸易站占位过滤先于几何测试。普通右键保留原有上下文优先级；显式驻扎模式对同一屏幕点上符合条件的自家接收建筑赋予优先权，防止攻击者模型遮住庇护目标。单位单选优先级仍允许在建筑覆盖区域选择单位。左键框选继续按投影中心判定，本轮没有将它改为网格相交。

验证包含：真实屋脊和基座选择、两档缩放下树冠及矿石边缘、右键树冠生成采集订单、建筑覆盖下友军选择、可见后退入已探索迷雾、资源死亡与模型池复用、实际驻扎后的旧视图、与资源投影重合的 UI 遮挡、施工体积增长。测试通过真实 InputSystem 事件流执行。结果和失败边界见本次测试报告；工程中存在测试文件本身不代表通过。
