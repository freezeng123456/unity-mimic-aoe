# 0.12 地图与任务工作坊

本轮补的是自定义地图与任务创作入口。官方《帝国时代 III: DE》的[场景编辑器说明](https://support.ageofempires.com/hc/en-us/articles/8476566769556-Scenario-Editor-Interface)把地形、水域、对象、玩家数据、触发器和试玩列为编辑流程；本项目按照这些功能类别补足原创实现。当前仍采用 128×128 米地图，不能读取商业游戏的场景文件。

本文说明操作与数据约定。候选1原生检查发现入口遮挡和结算原因问题后，候选2修复并独立通过1,286项完整测试；当前GUID `4546189bdd6b40fa92789fe697f7f0a7` 的编辑、试玩、单次奖励、源文件缺席的冷恢复、冷草稿/导出及录像前向重建已在实际客户端观察。范围及元数据见[069验证](Verification-069.md)，当前边界见[完成状态](Completion-Status.md)。

## 操作

从主菜单 `SCENARIO WORKSHOP` 进入。`NEW` 把九张模板的实际地形、河道、资源与地标展开成可编辑数据；原模板 ID 不作为用户地图内容的替代。

- `TERRAIN`：抬升、降低、平滑、压平、草地/沙地/泥地/阻路岩地笔刷。一整笔按下、拖动、释放算一次撤销，最高/最低高度为 100/−20 米。
- `RIVERS`：选择与拖动河道控制点、编辑每点半宽、追加或删除控制点、切换平滑曲线。`move bend` 按指定半径带动相邻控制点，方便修改模板中已经采样的河湾。
- `BRIDGES`：移动桥中心，编辑方向、跨距、宽度、坡道长度与桥面高度。校验检查两端落地和船只净空。
- `OBJECTS & RESOURCES`：选择、移动、放置或删除单位、建筑和资源，修改属主、建筑是否完工及资源量。
- `PLAYERS & STARTS`：2–4 个明确玩家席位、文明、队伍、初始时代与资源，分别移动城镇中心、探索者和每名初始工人。新席位默认有 300 食物、300 木材、100 金币的初始库存，可在面板修改；不会自动生成附近资源矿点，校验不会静默搬动用户放置的对象。
- `REGIONS`：编辑供抵达、占领与触发器引用的区域矩形。
- `TRADE & TREASURES`：修改贸易路线与站点、绑定中立盟友，编辑宝藏类型、位置及守卫位置。
- `OBJECTIVES`：手动、守区域、摧毁对象、抵达区域、资源阈值；可设置玩家、必选目标、前置目标与限时。可关闭常规全歼，任务完成允许敌军仍存活。
- `TRIGGERS`：时间、对象死亡、区域人数、资源量、目标成功/失败及其他触发器次数等条件；消息、增援、移动/攻击命令、资源奖励、目标成功/失败、胜负和启停其他触发器等动作。动作按照作者排列的顺序执行，类型选择可以直接选择任意项目。

`VALIDATE` 既检查格式/引用，也检查实际地形、导航、出生点、地基与当前时代上限。未通过地理检查的草稿仍可以保存供继续修图；`PLAYTEST` 必须通过开局检查。资源的目录半径用于选择和采集范围，不将森林或猎物登记为单位身体障碍，资源可以聚簇；单位之间的身体间距、建筑完整占地及地形通行仍须通过校验。校验通过不证明任务可解、AI 策略有效或对局平衡。实际指向攻击继续遵守视野和阵营规则，无法攻击尚未揭示的对象；任务作者可使用延迟触发器等待单位侦察。

试玩运行草稿的深拷贝。暂停菜单或结算菜单的 `RETURN TO EDITOR` 返回原草稿并保留撤销历史；试玩中的移动、采集、奖励和死亡不会改写作者的初始布局，也不会写入本项目课程/战役的账号完成进度。从检查点加载自定义对局则进入普通对局状态，不恢复编辑器会话和试玩返回标记。

## 保存和恢复

`SAVE` 将当前身份写入本机 `Scenarios` 地图库；`SAVE AS` 默认生成新身份。库最多容纳 128 个 JSON 文件，损坏文件也计入上限。`IMPORT/EXPORT` 读取或写出带完整内容哈希的便携场景文件；文件须符合当前规则和格式，默认导出到同一游戏资料根目录的 `ScenarioExports`，不污染地图库列表。导入失败保留原草稿和撤销/重做历史，损坏库文件显示原因而不拖垮整个列表。

替换已有草稿前，先在 `ScenarioDrafts` 写入完整便携恢复文件。除当前草稿外，最多四个最近内存草稿保有各自的撤销历史；`PREV DRAFT` 切换最近上一份，`DRAFT HISTORY` 可选择其中任意一份。撤销和重做各保留最多 32 步/8 MiB。更早的恢复文件可通过 `IMPORT` 打开；这些文件不自动清理，磁盘文件也不保存撤销历史。

关闭工作坊和正常退出时尝试写入 `latest.scenario.json`；新进程进入工作坊可读回最新文档，撤销历史从空开始。恢复文件写入失败时停止替换，关闭时写入失败则保留当前工作坊。强制结束进程之前的未持久化修改不保证恢复。

自定义对局的世界、存档与录像都包含冻结的地图内容和哈希，恢复不需要源地图库文件，但仍须满足应用、规则和构建兼容性检查。联机自定义地图明确要求四个作者席位，不能自动把两席地图补成四席；实际文明和队伍由合作大厅覆盖，初始资源与时代取自文档。房间与就绪状态绑定相同内容哈希，房主执行触发器，客户端应用权威状态。自动化的源文件删除后恢复检查不能替代当前构建的原生冷启动或联机实测。

场景文件、快照与触发器状态的具体合同见 [Scenario-069-Contract](Scenario-069-Contract.md)。地形总尺寸、对象/控制点数量、触发次数与增援预算均受有限上限约束。没有任意脚本执行、商业场景导入、运行中桥梁破坏、跨构建录像迁移或在线地图市场。
