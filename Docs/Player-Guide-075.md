# 0.18.0 玩家指南：使节、侦察与潜行

基础选择、指定目标攻击、曲河港区、革命和保存操作沿用[072指南](Player-Guide-072.md)，市场沿用[073指南](Player-Guide-073.md)。本页是操作说明，实际验收范围见[075验证](Verification-075.md)。

选择荷兰，普通时代I开局后左键点己方 **Pathfinder**。在右下操作区找到 **Envoy / 50F**，点击支付50食物，等待15秒训练。训练期间探险家可正常移动；驻军暂停训练，出口堵塞会等待。队列中取消可退回原支付。使节不占人口，存活和排队共同计入时代上限。

探险家的 **ENVOY RALLY** 用左键指定未来使节的地形集合点，可点世界或小地图；旗标显示实际目的地。右键或Esc取消指定。普通右键仍是探险家的移动/目标命令。使节仅能造贸易站：走到可见空贸易点附近，按B选择 **Trading Post**，支付200木材并实际施工；停止后右键自己的未完工贸易站可续建。使节不能采集、修理或领取宝藏。

选择法国，普通开局按 **T** 定位城镇中心，点击 **Native Scout / 50F 25W**，支付50食物和25木材，18秒后出兵，占1人口，上限4。新单位使用短弓，可以手动攻击，也承担侦察；**M** 军队循环不包含这两种侦察单位，出兵后用左键或框选选择。

选中使节、法国斥候或探险家，点击 **AUTO SCOUT** 开始自动探索。单位使用真实步行和视野揭雾，只按已知地形和可见敌人检查危险。点击 **STOP SCOUTING** 或按 **S** 停止；普通手动命令可接管。Shift追加命令按队列执行，侦察后面的命令在当前路段结束后接手。紧凑窗口可在右下操作区滚动找到这些按钮。

法国斥候点击 **ENTER STEALTH** 潜行，详情显示Stealth状态，姿态下蹲，移动速度降至60%；**LEAVE STEALTH** 主动退出。潜行仍揭开普通迷雾。指定反隐单位8范围内可发现它，受伤会揭露6秒；攻击/攻击移动等命令退出潜行，短暂冷却后可重入。最后一个存活己方单位不能隐藏。

侦察兵很脆弱，不保证穿过守卫或军队。需要指定目标攻击时，选中有武器的己方单位并右键可见敌人或建筑；潜行者必须先被探测或揭露，才能成为新的合法目标。既已发射的弹药仍可能命中潜行斥候。

保存、录像和LAN保留实际命令与状态；存档需匹配应用版本和规则，录像还需匹配构建身份。完整官方卡片、治疗与商业国家制度仍有差距，具体数值为本项目规则。
