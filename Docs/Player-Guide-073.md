# 0.16.0 玩家指南：市场兑换

基础选择、指定目标攻击、曲河港区、革命和保存操作沿用[072指南](Player-Guide-072.md)。本页说明新增市场；验证范围和原生交互限制见[073验证](Verification-073.md)。

选择工人，按 **B** 打开建造菜单，建造 **Market**。时代I即可建，费用100木材、建设30秒；等工人到达并真正完工。选择自己的完工市场，点击 **RESOURCE EXCHANGE**。

弹窗有 **BUY FOOD / SELL FOOD / BUY WOOD / SELL WOOD**。点击 **EXCHANGE: 100 UNITS** 切换100或500单位；按钮显示整批金币总额，交易会一次扣款并到账。余额不足时按钮不可用。选择 **KEEP PLAYING** 返回对局。

本项目的初始价格是买100食物或木材支付130金币，卖100食物或木材得到70金币。买入会提高该资源报价，卖出会降低报价，食物和木材分别计价。500单位包含五笔逐步变价的100单位，初始一次买500需680金币，卖500得到320金币；以弹窗当前总价为准。交易不会因钱包不足自动缩成较小批次。

例如，普通开局300食物/300木材/100金币，建市场后为300/200/100。初始卖100食物得到70金币，再按另一资源的初始价买100木材花130金币，余额应为200食物/300木材/40金币。这是规则示例；不是原生操作验收记录。

同一玩家的所有市场共享报价，拆建新市场不会恢复价格；对手有自己的报价。频繁往返买卖会付出价差。暂停、观战、自动观战或无法提交命令的网络状态下不能兑换；恢复可操作对局后看当前报价。市场兑换也会记入比赛报告和当前版本存档/录像。

矿区受威胁时，市场提供临时金币来源。长局仍应结合可采矿区、文明设施或贸易路线安排收入；没有富余食物或完整启动费用时，AI也可能无法恢复。
