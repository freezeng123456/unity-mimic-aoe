# 0.6.0 中文试玩指南

## 启动

解压 macOS arm64 客户端 ZIP，打开 Frontier Reckoning.app。菜单选择文明、时代上限、难度和卡组；地图按钮循环六张固定图。要看本轮内容，选择 Winding River Valley；其他新增图为 Tropical River Bay、Confluence Rivers、River Estuary，然后点击 BEGIN SKIRMISH。

原 Frontier Plains 和 River Crossing 保留。普通玩家失焦会暂停，回到窗口点击 RESUME。版本和客户端构建身份以本轮 manifest 与 Native 记录为准。

## 曲河试玩路线

1. 先让村民右键开局资源箱，分配食物、木材和钱币；维持村民及住房，正常升级到时代 II。
2. 选择村民，按 B 打开建筑栏，选择 River Dock。先调查河岸，在绿色预览处建造；仓库在岸侧，栈桥伸向水中。消耗 200 木，村民必须到岸侧实际施工。
3. 选择完工码头，训练 Fishing Boat；选择渔船右键鱼群。渔船会沿水路寻路并实际取得食物。AI 渔船会根据已知危险改派或撤离；玩家渔船需手动下令。鱼群资源有限。
4. 训练 Gunboat，右键一艘可见敌船或靠河敌建筑指定攻击，再右键另一目标换靶。船上炮弹仍受射程约束。
5. 框选一支混编陆军，右键对岸地面；部队寻找桥口并沿坡道过桥。船只可以在桥下通过。可以用 A 后点击攻击移动，S 停止，J 原地守卫。
6. 换图体验更宽热带河湾、三桥支流汇合和河口宽水面。每张图使用独立鱼点、码头候选岸位、商路与 AI 水上巡逻点。

## 常用操作

| 操作 | 功能 |
| --- | --- |
| 左键、框选、双击 | 选择、选择一组、画面内同类 |
| 右键 | 移动、指定攻击、采集、施工、修理 |
| T / V / M / F | 城镇中心、空闲村民、轮换军队、聚焦选择 |
| B / H | 建造栏、主城船运 |
| Ctrl 或 Command + 数字；数字 | 保存编组；召回编组 |
| Esc | 取消操作、关闭面板或暂停 |
| F9 / F8 | 保存原生截图；短时性能采样 |

## 当前范围

六文明、五时代与原有陆战内容继续保留。本轮没有运输船、登船/登陆、航运贸易、随机地图、可毁桥或文明专属海军。水纹、船员工作动作及尾流是视觉表现，水流不改变航速。新增棕榈和岸边装饰不提供采伐收入。

此客户端为 Unity 6000.6.3f1 / URP / Development / Mono / macOS Apple silicon。未验证 Intel Mac、Windows、Linux、跨机器签名或公证。没有存档、联网、战役或地图编辑器。验收图集是在 Editor PlayMode 中通过实际 URP 镜头拍摄的受控场景，原生客户端检查另有记录。
