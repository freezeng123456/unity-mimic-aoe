# 0.7.0 候选试玩指南

候选已通过最终自动化回归 796/796（466 EditMode + 330 PlayMode），已构建 macOS arm64 客户端并验证普通局的保存覆盖、进程退出/重启、菜单载入与续局。四文明受控工业展示、200/400 单位压力复测和正常规则 AI 自然终局也已归档，实际范围见[测试证据](Evidence/064/Tests/README.md)、[原生记录](Evidence/064/Native/README.md)和[完成状态](Completion-Status.md)。六文明、六固定地图与曲河港区沿用 0.6.0 的玩法；本轮第一批新增经典工业、本地续局和呈现优化，[后续路线](AoE3-Gap-Roadmap-064.md)中的随机地图、中立势力、运输船、联网及战役等仍未完成。

使用 0.7.0 候选的 `Frontier Reckoning.app`；Unity 版本为 6000.6.3f1，客户端 GUID 为 `48cbcf92c92f409c945f83eeb9b8d500`，完整身份见[构建回执](Evidence/064/Native/client-build.json)。打开后在主菜单选择以下配置并点击 **BEGIN SKIRMISH**。下载位置与独立校验文件见[交付索引](Delivery-064.md)，包的 SHA 以下载目录的 release-manifest.json 为准。

1. 主菜单选英国、荷兰、法国或奥斯曼，时代上限选 IV 或 V。经济、军事、科技预设已包含 Factory Wagon 和 Robber Barons，也可以在 25 张卡组内手动选择。
2. 正常开局采集、建造、升时代并赚取 XP。到 IV 时代按 H 发送工厂马车卡；这会消耗船运机会，并经过正常运输时间。
3. 选真实到达的马车，按 B 或 BUILD FACTORY，在已见且可建造的陆地放置。马车会移动到工地；跨河必须走桥。到达后消耗马车，工厂需要施工时间才能生产。每方最多两座工厂/马车（包括在途）。
4. 选完工工厂，在 FOOD、WOOD、COIN、ARTILLERY 中择一。英国产火箭，法荷产重型加农炮，奥斯曼产巨炮。研究暂停工厂生产；出炮需要人口和安全出口，切换模式会舍弃未完成炮的进度。工厂炮不逐门扣资源，代价是停止工厂资源收入。
5. Esc 打开暂停界面，SAVE MATCH 选槽 1–3。选择已有槽会替换该检查点。主菜单 LOAD SAVED MATCH 或暂停 LOAD MATCH 读取。载入后先保持暂停，点击 RESUME 继续；镜头、编组、AI、迷雾、命令、队列与工业进度随存档恢复。
6. F9 保存实际渲染截图与状态 JSON；F8 开始/结束性能观察。它们不会补资源或调整速度。

编组也可通过选中对象后的 GROUPS 面板使用 SAVE 0–9 / RECALL 0–9 按钮。此次原生冷恢复实际验证了 SAVE 2 按钮及数字键 2 召回，组合创建快捷键没有被该次验收覆盖。

存档位于 macOS 的 Unity persistentDataPath 下 Saves 目录。当前仅支持相同应用版本和规则；没有跨版本迁移、云存档、联网或通用回放。工厂与火炮战斗数值按本项目规则 P 调平衡，完整官方文明卡池、革命与教堂/军械库/国会仍待迭代。

受控工业展示存档只用于模型与操作面板检查：起始 IV 时代、补足的船运 XP 和仅含两张工业卡的展示卡组明确受控，AI 关闭，港区、马车、工厂和火炮仍通过公开命令与真实等待形成。该两卡卡组不是正常 25 卡开局验收；这类截图不能当作正常开局完成工业时代的对局证明。

正常开局原生 AI 验收为法国对奥斯曼、Standard、winding、16× 固定步模拟，1047.691 秒自然胜利。法国到 IV 后真实发送工厂马车、移动建厂并形成地基，终局前未完工，也没有正常开局重炮产出；不扩大为四文明完整工业对局或普通速度性能证明。
