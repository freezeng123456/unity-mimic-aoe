# 077 · 曲河两岸差异化精修

本轮按既定河流顺序继续，先精修 **Winding River Valley**。0.20.0 是新的地形身份，076 的原生截图、构建与测试保持原身份。

## 已接入源码

- 从真实曲河中心线的转向与岸侧计算内外弯，缓存到布局网格；查询侧不逐段扫描河道。
- 内弯扩大现有陆地上的沉积沙滩色带；外弯缩窄沙肩、加快低切岸上升。仍只有原有 0.42 米岸高，最窄上升宽度 2.2 米，并非高崖或新增浅滩。
- 地表网格与模拟使用同一份 BankHeight / BankLayers 查询，保持连续单网格混合。
- 首轮实际画面对照可见岸侧差异，但普通镜头辨识度偏弱；随后仅 Winding 独立缓存沉积沙色板，保持其他温带图色板。保护港址／桥头仍保持原高度与分层权重，沙色随 Winding 色板变化，不声称像素不变。
- 桥面、桥坡、港址及城镇周边回退原岸形，外围平滑衔接。水面、河床、可航行范围、鱼群、开局资源、桥位及三米外平地保持原合同。
- 其他河流图仍采用原剖面，本轮先验证一张图；热带河湾、支流和河口的后续精修不预填完成。

## 验收门槛

1. **地形合同**：独立的原始 Unity 陆水网格哈希、中心线控制点、鱼群与起点；真实左右岸符号；密集可行走岸线高度连续性。
2. **实际消费者**：公共 Move 到改变后的岸区并完成；两个独立 World 使用同一缓存布局的 warm/restore 逐 Tick 状态一致。该项不是独立布局重建或原生冷启动。
3. **网格接线**：读取实际 MeshFilter 的全部顶点和 RGBA，与共享查询一致；独立指定西内岸、东外岸的沙滩差异足够明显。
4. **可见画面**：实际 URP 普通游戏镜头的同位对照，随后新构建原生 F9。重建旧公式的诊断基线与真实旧版本截图分开标注。
5. **兼容**：曲河移动／输入、港区／运输／驻扎、旧地图、存读版本门槛及完整 Edit / Play 回归；测试、构建、原生操作、FPS分别记账。

## 后续顺序

1. 收敛 Winding 内弯沙滩、外弯低切岸的实际视觉效果。
2. 基于该岸形验证桥头调兵、指定攻击、码头投放与运输登陆，修正实际观察到的衔接问题。
3. 在既有船型基础上继续港区与船只轮廓、比例和动作精修，不把截图替代付费生产链。
4. 将经过验证的岸形语言扩展到热带河湾、支流汇合与河口潮岸；各图保持独立玩法合同与截图。
