# 0.2.4 原创火枪步兵：实际导入与视觉检查

本轮只替换 musketeer 身体。武器、单位属性和战斗规则保持0.2.3。源资产、许可与数字指纹见 Asset-Licenses.md；authoring合同见 Character-024-Contract.md。没有把单个角色研究当作阶段D完成。

## 发现和修复

第一轮委派试样因块体造型、相机倒置和无有效照明被拒绝，没有进入Unity。主代理重新构建收腰外套、头面轮廓、三角帽、衣片与马裤/靴；检查Blender正、侧、斜前方图，修正颈后头发、衣片深度、帽檐厚度及多边形法线。

初次FBX导入的X轴与Unity约定相反，左右肩、肘、手位置镜像；表面手掌距正确关节约0.59米。ImportedCharacterTests实际失败，原始XML保留在交付旁的Regression目录。修正源坐标转换与三角面顺序后，测试检查源肩/肘/手坐标误差小于1毫米，真实手掌在静止/瞄准姿态中距手部关节小于0.09米，并检查面向与身高。不是仅验证对象名称。

运行时重建游戏约定的关节轴，将导入表面保持世界位置后挂接到这些轴；导入器的坐标转换旋转不会成为动画轴。小部件按同枢轴/同材质合并，使用共享材质。上部白色衣片最后一处穿插也经Blender和Unity近景复查。

## 实际图像证据

交付旁 Verification-0.2.4/CharacterStudy 保存：0.2.3/0.2.4八兵种网格对比及保留网格法线的中性材质版；长枪/火枪/弓/骑兵/火炮四个姿态样本；火枪兵待机、准备射击、开火、装填近景新旧对比及中性版；2560×1440、50度俯角、orthographicSize=26的正常策略镜头下72单位编队（原/新版各一张）。所有Unity图使用真实URP RenderTexture渲染，非重绘画面。近景新旧共享当前0.2.4动作系统，比较的是身体网格，非两版完整动画系统的A/B。

主代理实际看过正/斜方Blender图、Unity准备射击彩色和中性近景、装填近景、火枪动作样本和正常策略镜头编队图。可见衣片已无此前胸口穿插，手掌与枪握持位置一致；正常镜头下帽型、蓝/白衣块与长枪兵有差别，脸部细节不会在正常距离可读。

这些是孤立模型诊断，不证明当前地图、HUD、声音、操作或最终画面质量。肩肘仍是刚性分件，有硬接缝；没有骨骼蒙皮、布料变形、指节握持、真实弹药/通条装填全流程。其他步兵、村民、骑兵、马体、建筑和地形仍是开发模型。需继续在真实客户端镜头、混编交战和动作过渡中检查。
