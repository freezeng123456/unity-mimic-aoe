# 0.2.16 · 双击选择与正常对局证据 037

0.2.16 修复快速点击两个不同位置的同类单位时，错误扩展为全屏同类选择的问题。双击必须是连续的友方同类点击，时间差大于等于 0 且小于 0.3 秒，释放点相距不超过 8 个 Input System 屏幕像素；距离沿用框选拖动阈值。右键、UI 手势、框选、小地图、键盘操作、选择/定位、目标模式、设备复位及暂停/焦点转换会清除候选。契约在运行时修改前冻结，见 [Double-Click-037.md](Double-Click-037.md)，属于 P 项目交互规则。

本轮先在封存 0.2.15 中完成一局正常玩家镜像对战，再定位选择缺陷。对局里曾观察到分配少量矿工后全部 14 名村民转去采矿，但该局没有详细输入时间日志，因此它只是与代码缺陷吻合的观察，不是精确重放。修复仅涉及 RtsInput 与版本号，不修改资源、AI、时代、船运、战斗或导航数值。

冻结的 7 项真实 Input System/UGUI 回归文件 SHA-256 为 `e42a72182b6e307bd596ae6d4dbba340809c0cad64e07b77fa9267deeb0488d5`。旧运行时连续两次均 3/7 通过：正常双击、空白点击隔离及超时单击通过；远距单击、右键、框选及 UI STOP 后的单击失败。修复后同一文件 7/7 通过。测试明确断言两个点击在 0.3 秒内，检查实际 Gather 和 Stop 指令，而非仅调用选择函数。全量 EditMode 119/119、PlayMode 148/148 通过。虚拟输入夹具不证明物理硬件或系统焦点恢复。
