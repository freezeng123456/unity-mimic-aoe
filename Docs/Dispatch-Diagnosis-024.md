# 0.2.4 对局调度差异诊断合同

0.2.3原生标准资源海岸/河谷自动局2663.5476秒结束、156654事件；同开局诊断3022.2976秒结束、181900事件。双方各时代时间相同，全部原始结果保留在Verification-0.2.3。第一处事件顺序差异在索引141/time0的双方训练付款。

假设按优先级：H1 AI调用顺序差异（诊断0→1，客户端1→0）足以造成后续实体ID/目标/队列差异；H2客户端输入/UI/表现额外写入模拟；H3按帧推进/数值环境造成差异。先只改变诊断AI顺序，与冻结原生事件逐项对照；不同版本号码不进入模拟规则，不改开局/费用/科技/卡牌/导航/战斗算法。若H1对照成功，再提取共享调度入口和真实入口回归，随后原生客户端重新运行。不能把一致的事件数当作全事件一致，也不宣称跨平台确定性回放。

人物正式网格为另一个独立开发试样，在work/中制作，未进入此因果诊断的运行时模型。

## 实际结果

仅调整诊断AI顺序的对照结束于2663.547607秒；156654条事件与0.2.3原生JSONL逐字节一致，SHA256为cee2523d45fdd9e2940883b4f76d9700334e7c86383a7f1a3f03cfadef4856eb。对冻结旧诊断运行Tools/compare-event-logs.py会在事件141返回FAIL；对修正顺序与共享入口的新诊断都返回PASS。此病例支持H1，H2/H3不是解释此差异所必需。

MatchSimulation成为GameController、StrategyAudit和BuildTools诊断的公共调度入口：按玩家槽位降序调用已启用AI，然后推进0.1秒世界步骤；正常玩家槽位不启用AI。AdvanceFrame处理分帧累积，暂停不积累时间，终局停止，过载最多每帧10步并限制待追赶量。4项测试覆盖注册顺序不改变调度、不同渲染批次得到相同实际事件、暂停/终局、不自动接管玩家。完整共享入口诊断再次与冻结原生156654事件逐字节一致。

范围仍是一台机器上的固定地图/种子/卡组病例与相应测试；不证明联网或跨平台确定性回放。
