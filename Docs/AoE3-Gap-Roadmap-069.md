# AoE III 内容差距与后续方向

2026-10-06。当前源码为 **0.12.0 地图与任务工作坊候选 2**。本页记录已有能力与下一批内容方向，不替代正式测试、原生操作或交付凭证。候选2实际通过1,286项完整测试，GUID `4546189bdd6b40fa92789fe697f7f0a7` 的受控原生编辑、冷存档/草稿、任务及自定义录像已分别记录；旧候选诊断保持原身份。具体状态见[完成状态](Completion-Status.md)和[已知限制](Known-Issues.md)。

此前四项河流任务——蜿蜒河谷精修、地图与玩法适配、港区与船只轮廓、热带/支流/河口扩展——保持各自版本的完成记录。后来的工业经济、地图海军、课程设置、回放和可信 LAN 批次也保持版本身份。[旧路线页](AoE3-Gap-Roadmap-064.md)保留这些批次的历史叙述，0.11 的 1,185 项测试、原生 GUID 和私有云盘只作为 0.11 证据，不能改称 0.12 结果。

## 落地顺序

1. 完成 0.12 候选 2 的测试、原生工作坊操作、冻结存档/回放及交付核验。旧版成功不代替新版本验收，草稿或存档损坏必须显示原因并保留现有状态。
2. 使用已落地的工作坊丰富内容：先做一张普通对局地图和一组相互衔接的原创任务，明确出生资源、贸易站/港区争夺、援军时机、胜负与失败路线。按普通规则试玩陆军点目标、绕河/过桥、船队运输、撤退和冷恢复，再扩大地图库。
3. 深化经典四文明的战略系统。每次集中补一个机制，包括界面、经济结算、AI 决策、联机权威命令和存档/回放；用实际不同的开局与中后期路线验证策略差别，再增加卡牌或文明数量。
4. 随可玩内容迭代模型、动画、音频和性能。先解决玩家辨识与调度中的具体问题，再增加装饰复杂度；地图平衡、自然比赛、长窗性能与两机合作分别记录结果。

## 参考与范围

官方[场景编辑器界面说明](https://support.ageofempires.com/hc/en-us/articles/8476566769556-Scenario-Editor-Interface)列出地形、水域、对象、玩家数据、目标、触发器和试玩等编辑类别。本项目借鉴功能类别，以原创代码与资产实现；当前不导入商业场景、不执行任意脚本，也未实现商业编辑器的全部工具。

商业游戏的完整文明、卡池、战役、美术/语音与扩展模式仍是后续差距。公开发布、扩大共享、合并或正式签名发行不由内容路线自动授权；私有开发分支、既有 draft PR 和既有私有云盘范围保持原边界。
