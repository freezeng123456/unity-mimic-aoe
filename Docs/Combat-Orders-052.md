# 战斗指令政策 / 052 / P

本文是本项目主动选择的规则说明，不是已核实的AoE III决定版补丁行为。既有参考来源与待核实部分继续保留在Reference-Combat-Shipments.md等文档中。

1. Hold要求当前位置作战，不主动追击。自动新选和记忆目标必须满足当前位置武器最小/最大射程；建筑同样不能靠移动进入射程。检测采用现有准备阶段的最大范围+0.1容差，强制近战的近战武器范围1.4，最小射程边界允许射击。
2. 普通自由作战单位可追击射程外且可见的目标；显式Attack保留玩家目标优先级。已准备射击仍遵守既有发射阶段判定，包括最大范围+1容差；052没有改弹丸模型或这个旧容差。
3. 非追加Attack若与当前队首直接Attack及当前attackTarget完全相同，视为重新确认当前意图，保留准备与冷却。它仍替换旧后续队列。仅队列后方出现过同一目标不足以保留准备。
4. 不同目标、Move、AttackMove、Stop、Hold等真实替换依旧取消准备；不退还已经开始的冷却。Shift追加不取消当前准备。只由模拟Fire产生实际发射，表现层不重复扣血。
5. 隐藏、死亡或已驻扎目标不能接受新的直接Attack；当前射击仍在Fire时重新验证。没有给自动选敌或AI增加迷雾后的实时敌方信息。

验证边界见Iteration-052.md。全部数值属于既有项目实现，未提升为原作已核实数值。
