# 0.2.3 升级计划合同（实现前记录）

此策略是 P 项目设计，不声称为商业游戏 AI 原规则。0.2.2实际对局中，河谷在721秒有24村民、8军人、约555食物/283钱币，729.57秒已重新支付军队费用。源码每次思考都要求8军人才能继续存时代资源，不能保持一个正在执行的升级计划。

本次先保持进入升级计划的村民/军队阈值不变，隔离“计划反复切换”这一原因。进入后固定目标时代，少量部队伤亡不会取消。目标时代已开始研究、已完成、城镇中心失去或经济伤亡严重时才结束本次计划。当前可见敌军侵入基地且己方少于4名军人时暂停储备，优先恢复防御；威胁缓解后至少20模拟秒再恢复储备。恢复经济或长期储备无进展（150秒）可退出并设置30秒再尝试间隔。

计划储备期间，兵营与马厩不能消费已有的时代费用，其他资源的富余仍可用于必要工作。村民建造住房、紧急替代采集设施仍可继续；时代费用在当前配置只用食物/钱币。暂不改变文明成本、开局资源、采集/银行速度、卡牌、单位属性或迷雾。

AI策略转变记录到真实事件日志：启动、暂停防守、恢复、取消/无进展及实际排入时代研究。记录是诊断用途，不产生XP或资源。暂停不推进决策状态。

验证：先验证少量伤亡不触发重复开支、真正可见的基地威胁可临时打断储备、完成/取消后不会保持旧目标、没有资源进展时不永久停产。再按0.2.2相同的六组标准资源/迷雾/卡组诊断比较，保留失败，随后独立客户端检查。任何“测试通过”“到了更高时代”都不等同平衡或玩家整局验收完成。
