# 0.2.17 · 村民视野检查与岩体占地

本版确认村民揭雾的既有行为，并将导航岩体从球形换为原创切面网格。没有修改视野数值、战争迷雾规则、经济、AI、科技或战斗。村民视野18米属于当前项目配置，不在此宣称为已核实的原作数值。存活、未驻扎且有正视野的己方实体均参加视野更新；驻扎单位由建筑提供视野。完整陆战与阶段D尚未验收。

038先对生产WorldView的雾面、贴图和Shader进行实际Unity/URP渲染诊断：非对称军队和村民位置正确揭雾，村民脚下及12米内清晰、24米外未探索，移除一支军队后该区域退回已探索。首次测试的暗区亮度阈值漏算线性色彩空间；修正测试期望后通过，没有改运行时透明度，初次失败保留。该夹具不能排除用户某个实际局部状态下的问题。0.2.17进一步进行了独立客户端村民外出/返回的手工操作，见Native-Verification-039.md。

GridNavigation.BlockedFootprint显式给出已有格子占用的外边界。1.8的配置半径沿用floor/round规则，占3×3个格子，物理边界为中心±1.5。WorldView用同一边界生成岩体底座，原有阻挡格不变，也不添加第二套Collider。此前Unity球体mesh半径实际为0.5，旧缩放后横向半径约1.98和1.89，超出阻挡边界；新网格解决了这项视觉占地偏差。

首个候选经Unity实际渲染检查后因尖顶外形被否决，第二版改为切角侧面与倾斜断面顶。每块96个三角形、288个展开顶点，独立面法线，无外部素材或全局随机状态改动。WorldView持有各代Mesh，在重开和自身销毁时释放。它仍是开发美术，没有据此认定整张地图达到最终美术质量。

全量EditMode128/128、PlayMode151/151通过。新增9项网格/占地检查，覆盖封闭面、有向边、法线、Unity球体实际半径、旧阻挡语义；新增2项岩体PlayMode检查覆盖同相机基线/候选实际渲染、三次重开及Mesh清理；另包含1项038迷雾渲染检查。未以全量测试通过代替自然完整对局、声音体验和长期性能验收。
