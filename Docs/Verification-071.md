## 明确的限制与下一步

原生日志仍出现 Mono 线程 `may have been prematurely finalized` 和 MemoryLeaks 分配诊断。最早的原生检查器没有匹配这两种文本；其原件不改，最终检查器副本修正匹配并保留原始行。进程退出 0 与这些诊断同时成立，不能据此认定零泄漏或长期稳定。生产队列中较长的英文标签也会挤出窄格，支付与取消仍实际工作，排版待修。

有四文明真实付费机制的完整自动化覆盖，原生代表只有英国受控 IV。正常开局路线仅 1/8 完整，国家制度/卡池/美术距离商业游戏仍有差距；两台物理 Mac 联机、长窗性能、冷目录大录像性能及发行签名公证分别未验收。下一批优先处理自然资源耗尽后的合法替代经济、核心重建预算和军事集结，不能用测试总数、受控通关或增加资金代替这些问题的解决。
