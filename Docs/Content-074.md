# 0.17.0 采集路线审查

074继续修正普通河流对局中工人往返危险资源区的问题。073的市场、真实储备与扩大集结候选保持；没有新增文明、模型或数值资源奖励。

AI现在用普通Gather实际采用的 `World.WorkPoint` 和未过滤寻路判断资源是否可采。工作点还须在实际采集边缘距离1.5以内，避免地形投影到远处后有路可走却无法获得收入。目标点安全而途中经过当前可见威胁时，不再以一条未被普通运动采用的安全备选路径批准任务。来源预测和派工共用这一判断，并验证当前任务保留的路径和绕行点；每次例行AI审查先处理危险任务，再应用12秒重新配额和每轮调整上限。可行时换到另一个安全且可达的资源点，否则通过正常命令撤回或停止，不产生补偿资源。

检查沿用既有经济威胁与迷雾规则，包含可见的中立武装守卫；隐藏、死亡或无武器守卫不能泄露进敌国记忆。玩家手动采集、实际Gather扣减/到账、驻军、军队6/10/14人真实抵达、保存/录像/LAN命令权威保持原合同。路线检查没有新增保存字段，临时几何与查询结果只在同步审查内使用。

这仍是**任务批准与定期复查**：两次审查之间新出现的敌人、单位避让、精细恢复和资源耗尽自动换目标仍由普通运动处理，在下次AI审查检查。它不提供逐帧安全约束、主动寻找另一条安全路线或护送，也不保证所有工人存活、所有资源区可拓展。

城镇中心存在时，军队Home先按原先的完工优先/最小ID规则选Town并返回，省去最终不会采用的救援扫描。没有Town时仍按原有可见危险和距离选择工人/农场/工厂/庄园作为恢复锚点。这是保持行为的局部优化；没有把共享主机约1.8秒慢步归因给Home，也没有测得帧率或整体加速倍数。

普通观察沿用073的三条开局、2400秒cap、1500比较点和30秒采样，新增采样时Gather任务数与不满足当前批准规则的数量。该数量还包含失效目标、不可达或不合资格，不能直接当作穿越敌区的次数；采样不覆盖两个采样点之间的完整轨迹。
