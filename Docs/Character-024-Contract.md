# 0.2.4 原创步兵网格合同

0.2.3仍使用立方体躯干与球头。本次先制作一名火枪步兵的原创三角帽、解剖头部、收腰长外套、翻领/衬衣、手部、马裤与靴的网格，替换此单位身体；武器和模拟保持原规则。其他兵种不自动套用尚未检查的制服，人物全套最终美术仍未完成。

初始代理试样因块体造型、错误相机朝向和无有效照明被拒绝，保留于work/character-024；不进入运行时。root重新用明确截面和部件构建可编辑Blender源，采用Unity坐标设计并转换到Blender，再输出FBX。身高目标约1.95米，保持肩/肘/手/腿的现有枢轴坐标与上下臂长度。无外部素材。除表面轮廓外，还需检查分件关节、衣物穿插、材质、正常游戏镜头和实际导入。

先查看正/侧/斜前方渲染，修正重叠衣片；同枢轴同材质合并网格以减少渲染器。Unity导入必须验证尺度/前方、材质槽、关节位置、真实武器轴与弦/手回归。通过后进入当前开发客户端，不能把Blend/FBX导出、自动测试或工作室机位图当作最终人物或完整游戏验收。
