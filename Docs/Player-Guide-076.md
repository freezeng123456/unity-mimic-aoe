# 0.19.0操作指南 · 医护

源码开发版说明，实测范围见[076验证](Verification-076.md)。既有[侦察指南](Player-Guide-075.md)、[曲河/运输/目标攻击](Player-Guide-072.md)继续适用。

1. 奥斯曼选择工人，B建Mosque（100W），正常升时代II后点击Imam（115F）。英国、荷兰、法国建Church（150W），时代II点Priest（100C）。等待30秒，需1空余人口；排队取消退原款，建筑毁掉损失队列投资。
2. 有武器部队右键可见敌人或建筑，仍是指定攻击目标；医生是独立支援，不随M军队选择自动冲锋。受伤兵退到可达后方，再停下来。
3. 选医生点HEAL，再左键受伤己方/队友。医生实际步行到范围内；双方移动或最近战斗会暂停，不会边走边回血。HUD显示实际速率、范围、患者和阻断原因。
4. AUTO HEAL让待机/Hold医生原地照顾附近合法伤员，不自动远追。Stop会关闭auto并清掉显式治疗；随后可手动重新打开。Shift依次指定患者，右键/Esc取消目标模式，普通移动/攻击指令接管。
5. 医疗单位选择按钮与M军队分开。时代III研究Mission Fervor，提升医生血量、治疗和自身训练速度，不提升全军。不要用十个医生叠同一个人的回血；同时多人负伤更适合分工。

存档与录像只保证相同应用/规则/构建身份下的已验证路径，075档案保留075app使用。原生测试、完整胜局/FPS、双物理Mac仍按验证页列实际结果。
