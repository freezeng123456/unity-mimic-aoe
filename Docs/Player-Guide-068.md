# 两人合作操作指南（0.11）

2026-10-06。本阶段已实现同一个发行客户端的可信局域网合作：你和朋友分别控制 P1/P3，合作对抗房主运行的 P2/P4 AI。两端须使用同一份完整解压客户端；同版本号的不同构建也可能被兼容检查拒绝。当前 Candidate3 完整测试 1,185/1,185 通过，同机双原生进程已实际操作并通过独立元数据/UI和录像容器/账本核对；正式交付仍在收尾，两台物理 Mac 的正式验收未完成。见 [068 完成状态](Completion-Status-068.md)。

1. 房主在主菜单打开 LAN CO-OP，保留默认端口 47621 或两端约定相同端口，点击 HOST CO-OP。
2. 朋友在同一局域网填写房主地址和端口，点击 JOIN HOST。房主在自己的 macOS 网络设置中查看当前局域网地址；两台设备之间填写房主的 LAN 地址。
3. 两端选择自己的文明和牌组，点击 READY。房主在 READY 前选择地图、目标、种子与 AI 难度；大厅显示连接、等待哪一方准备或双方准备完成，双方准备后由房主点击 START CO-OP。要改文明或牌组，先点击 NOT READY。
4. P1 和 P3 各用自己的资源、人口、单位与牌组。选择部队后可右键指定敌军或建筑攻击，也可通过 ATTACK 目标模式点选目标；迷雾内目标仍受原有可见性与接近规则约束。
5. 训练、建造、研究与升时代先显示 pending，房主确认后显示实际结果。不要把 pending 当成已经付款或完成；队列与资源以同步状态为准。
6. Esc 或切换到别的窗口打开本地菜单，比赛仍可继续。PAUSE MATCH/RESUME MATCH 是双方共享的模拟暂停；失焦不会替全房间暂停。
7. 短暂断线时客户端停止新的下令并等待恢复，房主可继续游戏；30 秒宽限到期远端席位由房主投降。显式 LEAVE ROOM/LEAVE MATCH 会离开该会话，不能再恢复这个席位。房主消失时客户端保留最后画面，离开后才能开始其他模式。
8. 房主可在菜单 SAVE REPLAY；客户端不另建录像/报告或单机检查点。观看这段录像时须保留原客户端构建。

生产栏点击某个未完成任务会按它的稳定身份申请取消并退款；实际结果仍须房主确认，任务已经完成时会拒绝，不会改为取消或退款后续任务。LAN 模式的普通 SAVE/LOAD、战役与回放打开需先离开合作会话。单机模式仍沿用失焦自动暂停、回来手动恢复的行为；LAN 的失焦菜单只影响本机输入。

当前客户端为 Apple silicon macOS Development/Mono，未做正式签名 Release 或其他平台验收。联网范围与证据见 [LAN 实现](LAN-068.md)；单机、录像与原有操作见 [0.10 指南](Player-Guide-067.md)。
