# 0.14.0 操作 · 革命与恢复生产

以下按当前规则说明操作；原生验收结果另行记录。

1. 选择英国、荷兰、法国或奥斯曼，在五时代比赛发展到时代 IV。选中完成的城镇中心，打开革命预览。先检查资金、现有工人数及经济停止的影响，再确认支付。
2. 队列需要 90 秒。点击该队列可正常取消并退回已支付成本；城镇中心被毁会损失这笔投入。革命期间不能再加入新的工人训练或工人船运。
3. 完成后，原来的陆地工人变成革命志愿兵。既有选择和控制组保留单位 ID。用正常右键指定敌方单位或建筑；收集补给时，右键自己的物资箱。自然鹿、树和矿不能替代革命补给。
4. 按 H 打开母城。当前卡组提供志愿兵、食物箱、工程补给和国别支援。物资船运需要自己的 35 秒运输，箱子落地后还需要收集；资源栏不会因点击船运立即增加。
5. 准备 400 食物和 400 金币，在城镇中心选择 CIVILIAN GOVERNMENT，再点击 REBUILD CIVILIAN GOVERNMENT 支付研究。60 秒完成后，可以按本文明正常方式取得工人。现有志愿兵保留军事身份，比赛仍停在时代 IV。
6. 招工被人口卡住时，先从运输船或建筑放出要遣散的陆地单位，选择 DISBAND 并确认释放其实际人口占用；KEEP UNITS 可取消。普通工人也可被遣散，选人时须注意。遣散不退款。英国、法国和荷兰还需首名工人的实际价格；奥斯曼等待自己的正常自动招工计时。
7. 新工人可以重新采自然资源、建房和修理。正常菜单 SAVE/LOAD 保留未完成政治队列；加载后先观察暂停状态，再 RESUME。录像库的冷首开仍需要完整验证，之后目录刷新可复用当前进程中已验证的元数据。

革命是永久放弃时代 V 的分支。平民重建恢复的是经济生产能力，并不撤销革命或重新发放旧卡牌。四个分支的国别支援与经济差异见 [内容合同](Content-071.md)。
