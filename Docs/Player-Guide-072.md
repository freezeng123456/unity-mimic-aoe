## 开始自己控制的对局

从主菜单配置文明、牌组、地图、种子、AI难度与时代上限，点击 **BEGIN SKIRMISH**。普通单机由你控制自己的席位，其他席位由AI控制；队伍和自由混战按当前配置执行。时代I地图开局需要正常采集、建造与发展。

如果顶部或命令栏显示 **AI OBSERVATION**，当前是AI自动观战，左右双方均按配置自动行动。你可以选择对象、查看DETAILS、聚焦或移动镜头，但不能向军队下令；右键、生产与直接攻击操作不会向对局下令。返回主菜单再点BEGIN SKIRMISH开始可操作对局。录像观看也只允许观察。工作坊的PLAYTEST保持人类控制与正常1×试玩，不沿用自动观战的下令模式。

## 指定某个敌兵或建筑

1. 左键选部队，或拖框选择一队。确认选择的是自己的部队。
2. **右键当前可见的敌方单位或建筑**，下达指定攻击。命令针对所点目标；敌人移动时，能够追击的部队会继续接近并攻击。命中仍受射程、兵种、碰撞、地形、目标存活及视野规则约束。
3. 要攻击途中遇到的敌人，点击 **ATTACK MOVE [A]** 后点地面目的地；在该模式点可见敌人也能指定该对象。右键空地是普通移动，不等于攻击移动。
4. **STOP [S]**取消当前行动；攻击冷却仍正常推进。**HOLD [J]**守当前位置，不主动追远处目标。右键新目标会替换当前非排队命令；按住Shift追加后续命令。

Ctrl+0–9保存编组，按对应数字召回；FOCUS [F]聚焦选择。默认T、M、V分别选城镇、军队、闲置工人，H打开母城；改键后以设置和当前按钮提示为准。选择、命令与到位是不同步骤：看实际单位位置、目标损伤与队列反馈，不能仅凭点击认定已经到达或造成伤害。

## 曲河上的集结与运输

陆军必须走可通行的桥和岸线路径；画面上离得近的对岸或长墙后方，不等于已经在集合点。选择生产建筑，右键地面设置集结旗；点可采资源可设置资源集结旗，新单位仍要实际走出建筑。

要渡没有陆路的水面，选陆军点击 **BOARD** 并点自己的运输船；船到目标水域后，选船点击 **UNLOAD**，点开放的陆地岸线。运输舰到水域和乘员真正登岸分别检查，船沉会损失乘员。选受损船用 **HARBOR REPAIR** 并点自己的完工码头，抵港后按实际费用维修。更多远征操作见既有[曲河指南](Rivers-063.md)与[070内容](Content-070.md)；旧GUID通关保持原身份。

072对手AI会把陆军实际集中后再出发，后续新兵先在集结点形成补员批次，尽量留守；当前可见军事威胁进入经济线时优先防守。这是AI策略，不是你手动部队的强制行动；普通对局中对手AI不会接管你的指定攻击。

## 提前接续木材与金币

树与矿是有限来源。不要等最后一棵树耗尽才安排替代收入。建筑仍需要真实付款、工人或工厂车，以及建设时间；主菜单、牌组和时代决定哪些渠道当前可用。

| 选择 | 费用与操作 |
|---|---|
| 自然树/矿、己方箱子 | 工人右键合法来源采集。母城物资不是点击即入账，必须等运输、箱子落地、真正采集 |
| Farm与Coin Estate | Farm300W提供农业来源；Estate500W提供金币来源。工人需真正建成并工作，不能把Food/Coin设施当木来源 |
| 荷兰Bank | 350F/350W，正常完成后产生金币收入；不能以建造按钮已点击当完工收入 |
| Trading Post与Cargo Ledgers | 在当前可见的合法trade socket付200W建站；完工后TECHNOLOGIES中研究Cargo Ledgers，200W/150C、45秒。选择站的WOOD/COIN等奖励，等真正路线车到站后到账；未解锁时只可用相应默认奖励 |
| 合法IV Factory | 通过当前文明的正常工业货运获得Factory Wagon；选车BUILD FACTORY放在当前视野合法位置，车在地基放置时消耗，工厂仍需60秒建设。完工后选FOOD/WOOD/COIN/ARTILLERY；造炮与资源产出互斥，研究会暂停生产，切模式会重置造炮进度 |

Cargo Ledgers也可能由当前合法牌组中的真实科技货运取得，以母城/研究的实际可用性为准；没有那张牌或运输机会时不能直接取得。Trading Post路线奖励与原创Wayfarer的付费货物车是不同机制：后者在城镇装付费货，到waystation才赚币，手动Move/Stop或损毁会损失货物。

英国Manor为135W；其他五个文明住房为100W，具体价格和可用设施以自己的当前菜单为准。各文明工人来源、数量上限与升级不同，不能把奥斯曼自动招工当所有文明免费工人。

## Town被毁后

有活工人时，保留500W，找到当前可见、可建且能让工人真实到达的安全位置重建Town。右键已付款但未完成的地基续建，不需要重复支付原建造费。注意可见炮楼、守卫、敌军和路口；看起来空地合法，不代表以后不会遇袭。

AI的共同恢复预算会保护其Town和关键收入启动，连续维修也不应吃掉这些费用；人类玩家仍能按正常规则自行决定支出，没有替你自动冻结500W。若已经没有工人、没有木来源或付不起完整贸易启动，恢复可能失败；游戏不会补送资源或强行结束战斗。

在危险前使用GARRISON [G]点自己完工且有容量的建筑；容量在到达时再次检查。需要出来时选建筑UNGARRISON。修理会正常花费，生产、住房、维修和重建之间应查看实际钱包与队列。

## 革命与恢复工人

经典英国、荷兰、法国和奥斯曼在五时代比赛的时代IV，可以继续升V，或选完工Town的 **REVOLUTION** 预览。确认革命支付800F/800W/800C，队列90秒；取消退实际已付费用，Town被毁则按生产损失规则处理。完成后永久放弃时代V，活陆工保留ID变为志愿兵。


生产队列的倒计时在47像素高按钮内使用18像素高文本区，当前版本已用PlayMode真实付费革命队列验证90s/88s字形生成、边界与取消退款。HUD通常约每一秒真实时间刷新一次队列；模拟加速不等于每一模拟秒重画，按住鼠标时会延后刷新以保护点击对象，卡顿也可能推迟。不要把画面倒计时暂未更新当作队列已经停止；查看实际队列完成与资源反馈。E原生原图已独立核对初始革命90s及后来50s/17s、政府60s倒计时；这不承诺所有长标题、尺寸和缩放都已观察。

志愿兵能战斗及采己方食物/木/币箱，不能采自然树矿、建造或维修。H打开当前革命四卡，部队和物资各自按正常运输规则到达，满人口兵卡不能当作已经落地。选Town的 **CIVILIAN GOVERNMENT → REBUILD CIVILIAN GOVERNMENT**，支付400F/400C并等待60秒；随后英国/荷兰/法国仍付首名正常工人的真实价格，奥斯曼等待正常自动招工。现有志愿兵不反向变工人。

若人口阻塞，可先把乘员卸下/放出，选活自有陆地单位 **DISBAND** 并确认；KEEP UNITS取消。遣散不退款、不发击杀经验，普通工人也能被遣散，确认实际选择。政府研究完成、首名工人出现、正采集收入是三个不同结果。两原创文明保留其既有时代路线。

## 保存、暂停与录像

Escape打开菜单。单机失焦可能暂停，回来先查看是否暂停，再RESUME；自动观战与LAN的失焦规则不同。SAVE MATCH选择SLOT 1/2/3，确认成功后才能依赖该检查点；LOAD SAVED MATCH恢复后先暂停。保存记录AI当前波次与政治/生产状态，不重新赠送已经领取的资源。

SAVE REPLAY保存已录区间；RECORDING LIBRARY打开后默认暂停，用PLAY/PAUSE、SPEED、视角、时间轴观看。录像不能向部队下令，也不能代替可继续操作的检查点。加载较晚检查点后新录制段从该StartStep开始，不能说它包含第0步以来的整局。F9保存原画面和附属JSON，不是录像或完整验收。

存档和录像严格匹配应用/规则/buildIdentity。保留生成文件的原应用；071到072的原生跨版本迁移、同版本不同GUID回放、云存档均不承诺。合作LAN须同发行包与可信局域网、使用LAN CO-OP大厅，历史同机双进程不证明双物理Mac整局已经验收。
