# 完成状态与交付证据 — 0.3.1

2026-10-04，经典文明首批玩法已经实现：英国、荷兰、法国、奥斯曼，加上保留的远驿盟市和山岭工联，共六文明。冻结源码通过 **284 EditMode＋243 PlayMode，共 527 项测试**，零失败、跳过或不确定项。原36组合矩阵 **35局自然结束、1局山岭内战超时**，所有涉及四经典文明的32组均自然结束；同组独立延长观察在3652.01秒自然结束，保留原35/36统计。初构建完成两场法奥16x自动原生整局；最终源码仅菜单排版与新增布局回归发生变化，最终客户端已重新构建并完成1600×1000菜单回查；源码包从证据与文档提交后的清洁HEAD打包，实际提交和SHA由交付manifest记录。

本轮实现经典文明的核心经济约束、兵种角色和发展选择。它不是《帝国时代 III》的完整国家内容、完整官方卡池或商业游戏内容量复刻；具体数值仍是本项目候选平衡。0.3.0 的四文明、480 项测试和 16 局矩阵保留在[057 完成状态](Completion-Status-057.md)。原 A–D 里程碑与 0.2.32 记录保留在[056 完成状态](Completion-Status-056.md)，不作为本版新实战。

## 菜单修订与失败记录

初构建1600×1000返回菜单时，奥斯曼简介覆盖PRESET/EDIT DECK。首次新回归[Tests-Menu-First](Evidence/058/Tests-Menu-First/failure-record.json)因把Unity缩放后的像素字号6误当逻辑字号而失败，PlayMode为242/243；换算修正后，[首次定向测试](Evidence/058/Tests-Menu-Targeted-First/failure-record.json)真实检出0.4比例下全文底边-82.5超出80高度。两轮失败原样保留。

最终把摘要高度从80增至104，卡组、开始、退出按钮均下移24；字体在14–17逻辑字号内适配。新增回归同时检查实际GameView比例和原生比例1，比较不截断全文与实际可见字符并校验全部字形边界，避免以截断隐藏文字。[最终定向测试](Evidence/058/Tests-Menu-Targeted-Final/Menu-layout-final.xml)和最终全量527项均通过。[精确源码连续性核验](Evidence/058/menu-equivalence.json)确认385文件中383相同，只变更`FrontierHud.cs`和`ClassicCivilizationUiTests.cs`，无新增/删除；规则、模拟和AI没有变化。初矩阵和原生整局保留原身份，最终客户端只重新核验菜单，1600×1000实际截图确认完整简介与按钮分开。
