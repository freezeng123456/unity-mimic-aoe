# AoE III 内容差距与后续方向

2026-10-06。当前源码为 **0.13.0 河流内容候选2**，一张普通经济曲河图和三章相衔接的原创远征已经实现。正式回归1364/1364通过，Mac构建成功；三章原生通关与侦察检查点新进程恢复已完成。候选1的1363项和真实画面保持诊断身份，其过早骑兵遭遇已促成修正。具体结果见[完成状态](Completion-Status.md)、[已知限制](Known-Issues.md)、[内容](Content-070.md)和[操作](Player-Guide-070.md)。

此前四项河流任务——蜿蜒河谷精修、地图与玩法适配、港区与船只轮廓、热带/支流/河口扩展——保持各自版本的完成记录。后来的工业经济、地图海军、课程设置、回放和可信 LAN 批次也保持版本身份。[旧路线页](AoE3-Gap-Roadmap-064.md)保留这些批次的历史叙述，0.11 的 1,185 项测试、原生 GUID 和私有云盘只作为 0.11 证据，不能改称 0.12 结果。

当前规则目录有 6 个文明、66 个实体、219 个科技、153 张卡和 72 条升级选择。这些是规则条目数量，不代表 72 种独立策略，也不证明商业游戏内容等价。具体经济/战斗数值继续采用项目规则 P；未获对应官方一手证据的数值不标为《帝国时代 III》原值。

## 落地顺序

1. 070候选2完整回归、构建、三章原生通关与侦察检查点恢复已完成，收口私有交付，保留候选1发现的遭遇节奏问题及旧证据。补齐普通曲河图付费扩张/海军与自然比赛样本，分别记录胜负、机动、投入和未完成情况。
2. 下一批优先深化经典四文明的革命与民生重建分支。利用英国庄园、荷兰银行、法国高效工人和奥斯曼自动招工的已有区别，形成即时军事力量与长期经济的机会成本；此项目前是方案，尚未实现。完整机制须包括支付/取消/失败、稳定工人转化、旧队列及在途船运、生产权限、民生研究、界面、AI与存档/录像，避免重复赠兵或重置卡牌。
3. 逐文明记录普通I时代开局的升V与革命两条策略；真实付费与自然结局分别验收，再扩大卡池和制度。受控IV时代契约测试只证明生命周期，不称普通经济路线已经可玩或平衡。
4. 随可玩内容迭代模型、动画、音频与性能。先改善单位/港区辨识和调度中的实际问题；长窗性能、两机合作与自然对局平衡仍分别测量。

## 参考与范围

官方[场景编辑器界面说明](https://support.ageofempires.com/hc/en-us/articles/8476566769556-Scenario-Editor-Interface)列出地形、水域、对象、玩家数据、目标、触发器和试玩等编辑类别。本项目借鉴功能类别，以原创代码与资产实现；当前不导入商业场景、不执行任意脚本，也未实现商业编辑器的全部工具。

商业游戏的完整文明、卡池、战役、美术/语音与扩展模式仍是后续差距。公开发布、扩大共享、合并或正式签名发行不由内容路线自动授权；私有开发分支、既有 draft PR 和既有私有云盘范围保持原边界。
