## 必须追加的证据

先跑规则与场景生命周期，再构建原生客户端检查菜单配置、卡组编辑、实际费用和科技面板。自动双文明对局必须记录实际银行收入、金币村民、炮兵生产/攻击与时代推进。逐个时代/科技的规则覆盖不能代替真实正常开局整局；人工主动侦察/混合军队/攻城/胜利路径仍要补齐。

导航新增测试必须包含不重叠的混合单位、每人不同目标、完整阻隔只留通道、所有单位抵达且沿途不穿障碍。槽位数和两条路径不能证明100/200单位通行。400与桥梁专项、贸易宝藏、成熟AI、最终美术动画音效和长期性能仍属于目标，不因本轮范围而删除。
