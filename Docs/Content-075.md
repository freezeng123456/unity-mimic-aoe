# 0.18.0 国别侦察内容

075补荷兰使节、法国原住民斥候、自动侦察与潜行。它们具有实际训练、付款、移动、迷雾和攻击权限；文明仍为六个，实体从67增至69。既有村民、工兵、探险家、文明兵种与关卡开局保留。

| 单位 | 训练入口 | 用途与代价 |
|---|---|---|
| 荷兰 Envoy | 荷兰 Pathfinder | 50食物、15秒、0人口；120HP、视野28、速度5；弱拳击。可在当前视野的空贸易点支付正常费用并实际完成贸易站，不能采集、修理、制造或领取宝藏。存活与排队共同计入时代I–V的3/5/8/13/18上限。 |
| 法国 Native Scout | 法国城镇中心 | 50食物+25木材、18秒、1人口，上限4；100HP、视野28、速度5；短弓远攻与弱近战，能够潜行。 |

训练只在完成并可用的己方入口进行。探险家移动时训练继续，驻军时暂停；出口堵塞等待，不能隔墙或跨水产兵。取消未完成队列退原支付，入口死亡损失投资并释放预留人口。使节有专门的地形集结点操作，普通右键仍移动探险家。

AUTO SCOUT给两种新单位及既有探险家追加真实侦察命令。它从己方迷雾前沿选择可达地点，按实际普通路径与当前可见武器检查风险；发现危险时尝试已知地形中的真实局部撤退。每1.2秒复核，不能保证两个复核点之间绝对安全。手动移动、Stop/Hold可接管，Shift排在后面的命令会在当前侦察路段完成后接手。新单位不算作AI军队人数，也不会得到村民或探险家的其他权限。AI在经济与升级储备允许后付费维持一个本国斥候。

法国斥候潜行时速度为60%，仍按正常视野揭雾。普通士兵的地图视野不等于反隐；探险家、两种斥候、完工城镇中心和塔楼在8范围内探测，中立守卫只在自己的实际视野与8范围内探测。已出手的弹药仍可命中，受伤揭露6秒；攻击、攻击移动、建造和领取宝藏指令会打破潜行并触发3秒恢复。最后一个存活己方单位不能继续隐藏。驻军、登船和死亡立即退出潜行。

造型采用原创程序网格：使节为高窄帽、分叉长外套、文书包与空手拳击，实际建造时取出锤子；法国斥候为低头巾、单侧短披肩、箭袋与短弓，弓弦随手拉动，箭弹保留真实飞行时间且没有枪口闪光。潜行姿态与自动侦察走路读取实际状态。
