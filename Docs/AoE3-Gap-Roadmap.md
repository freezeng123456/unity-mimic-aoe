# AoE3内容差距与后续方向

2026-10-09。当前075补上荷兰Envoy、法国Native Scout、自动侦察/潜行与探测，以及真实训练、贸易站建造、国别模型和操作反馈。六文明、69实体、220科技、169卡和72升级选择不代表同等数量的独立策略，也不等于商业内容量。[075内容](Content-075.md)、[验证](Verification-075.md)、[限制](Known-Issues.md)。

1. **侦察内容进入试玩。** 专门85例、完整1723例及同源码构建通过；两局普通AI实际付费使用新兵（1自然终局、1cap），两国原生训练/侦察、法国潜行与冷恢复已操作。交付原客户端、源码和原始证据到既有私有云盘，继续收集可复现问题；原生录像播放与FPS仍待验证。
2. **治疗与国别军事制度。** 在已有四经典/两原创文明中增加职责明确、付费且可被攻击的治疗来源，随后逐文明完善皇家卫队/特色升级、相应卡组和政治选择。先限定治疗目标、战斗中断、队列/人口、保存/LAN/录像规则，再验证真实兵力恢复和经济代价；不先堆定义数量。
3. **河流与海军实战。** 在既有蜿蜒河谷、热带河湾、支流和河口上加强港口争夺、河运保护、岸炮/舰种分工与付费舰队对抗。保留真实陆水通路、渡点、登船卸载和曲岸码头占位，按普通局与可操作画面验证。
4. **规模、动作与可读性。** 从实际慢步隔离军队Review、寻路与经济来源扫描；同输入状态与事件比较性能。继续改善劳动、装填、伤亡、建筑破坏、国别轮廓与语音。原生FPS和默认镜头下的可辨识性需要本构建实测。

075没有新增开局赠兵或改写旧关卡开局。经典机制参考官方[14.43676](https://www.ageofempires.com/news/age-of-empires-iii-definitive-edition-update-14-43676/)与[19.18309](https://www.ageofempires.com/news/age-of-empires-iii-definitive-edition-update-19-18309/)，具体数值和AI政策为项目规则P。旧[074路线](AoE3-Gap-Roadmap-074.md)与[073路线](AoE3-Gap-Roadmap-073.md)保留原验收身份。
