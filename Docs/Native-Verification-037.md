# 037 原生 0.2.16 输入检查

本报告覆盖本机构建后的局部输入检查，不是完整经营或主动攻城验收。正常经济镜像对局使用的是旧版 0.2.15，单独记在 [Normal-Player-037.md](Normal-Player-037.md)。

实际构建：0.2.16，GUID `af1e524273704830bbd0445a24446435`，Unity 6000.6.0f1（正式非 LTS，f7f8ed4d1e24），URP 17.6.0，macOS arm64 / Mono / Development / Metal。机器 Apple M4 Pro、14 CPU 核、48 GB、macOS 26.5 (25F71)，原生渲染 2560×1440。通过 .app 入口启动，诊断参数 `-frontierInputTrace` 只记录输入。Sky 操作真实应用鼠标键盘，F9 保存 Unity PNG 与配套状态，没有从测试夹具加载单位、资源或比赛结果。

主检查局 `41627f03e2544493ab4a81b4621b5780`，coast 镜像、seed 314159、时代上限 V、autoplay=false、速度 1，在 **134.199 秒主动认输**。一名村民采集约 33 F；玩家没有生产、时代升级或船运。本局以验证选择为目的，不能称正常完整对局或自然结束。
