# 河流远征操作 · 0.13.0

主菜单打开 **MAP, SEED & OBJECTIVES → RIVER EXPEDITIONS**。这里有一张普通经济对局图和三章原创远征；也可以从 **RIVER CAMPAIGN** 进入远征。右侧 **EDIT COPY** 会在工作坊打开独立副本，试玩副本不会取得战役解锁。

| 内容 | 操作与取舍 |
|---|---|
| Traders' Bend | 选择地图后回主菜单配置文明和难度，再开始。两方时代 I 正常资源开局，需要付费建港、生产舰船；南北桥、前线矿木、贸易与河道提供不同扩张路线。地图支持普通歼灭及可用的港区、守桥、车队目标。 |
| 双桥侦察 | 探路者实际进入对岸侦察区，然后部队摧毁封锁市场。先消灭守军有助于减少损失；西侧瞭望点有一次120木补给。侦察完成会触发营地突袭，应保留防守能力。 |
| 渡湾护送 | 六名指定登陆兵至少四人进入指定运输舰，并随它抵达护送水域，然后在岛岸卸载、走入岛内、摧毁封锁市场。护航艇可压制敌艇，也可以选择另一条水道。空船、工人或其他部队不能替代指定登陆兵。 |
| 守港回撤 | 在真实陆海反击下守住港区40秒，再让至少四名指定后卫抵达后方营地。可以过桥或用运输舰撤回。摧毁可选仓库可取得一次100木、80币，受损船仍需通过港口正常付费修理。 |

远征首章直接开放；完成后解锁下一章。原三章河流战役仍单独保留。每章明确给出部队、时代和补给，章节之间不继承军队或资源。

拖框选择部队，右键可见敌人或敌方建筑即可指定攻击；右键地面移动。攻击移动会沿路线接战。目标点击需要实际可见，不能隔着迷雾指定未发现单位。数字编组与聚焦快捷键可在设置中查看或修改。

选定陆军后使用 **BOARD** 并点自己的运输舰；选中运输舰后使用 **UNLOAD**，点开放的陆地岸线。船到达水域与士兵登岸是分别检查的步骤；船沉没会损失乘员。选中受损船后使用 **HARBOR REPAIR**，点自己的完工码头，靠港后消耗资源修复。

菜单提供检查点保存/载入、重试和本地录像。当前构建的检查点包含地图、指定成员、任务进度和触发器状态；载入不会再次发放已领补给或重复生成增援。录像只验证所记录的区间。跨构建兼容和两台物理设备联机仍不属于这批验收。

实际试玩建议：护航先让炮艇抵近敌舰，再送载兵运输舰进入护送区；运输舰不要停在敌舰射程中等陆军。守港先收拢后卫、用探路者协助拦截，火枪兵对骑兵可切近战，增援步兵出现后切回远程集中火力。敌人进入标记会把连续守港计时清零；至少四名指定兵必须真正到位后再驻守。暂停可用于查看和下达阶段计划，发出移动后要等部队实际到位再HOLD。此次原生护航走西渠、撤退走桥；其他路线仍需独立试玩。
