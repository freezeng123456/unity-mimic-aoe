# 烽岸纪元 · 0.2.31

独立原创 Unity 陆战 RTS，使用本项目规则和数值。当前客户端面向 Apple silicon Mac，四个原定里程碑的最新结果见 [Milestones-055.md](Milestones-055.md)。

## 启动

解压 `Frontier-Reckoning-0.2.31-macOS-arm64.zip` 后打开 `Frontier Reckoning.app`。菜单可选择海岸/河谷文明、时代上限、AI难度与25张卡组，点击 **BEGIN SKIRMISH** 开局。源码包通过 Unity Hub 使用 **6000.6.3f1** 打开，主场景为 `Assets/Frontier/Scenes/FrontierSkirmish.unity`。包内 `manifest.json` 记录准确提交、构建GUID和文件SHA。

## 经营与战斗

框选村民，右键开局食物箱开始采集。箱子到货后需实际采集；消耗完后工人会寻找附近同类资源。食物用于海岸村民、步兵和升时代；木材用于建筑；钱币用于河谷村民、火枪兵、骑兵、炮兵与高时代。

**T** 选择并定位城镇中心。右键资源设置新村民的采集集结点，训练村民和升时代占用城镇中心队列。时代II需800食物，III需1200食物/1000钱币；选择奖励后等待升级完成。

选中村民按 **B**，选择建筑后点击地图放置。多人施工更快。海岸的庄园完工赠送村民并增加人口；河谷拥有有限银行，其完工后自动产币。军营/马厩从II时代开始，铸炮厂从III时代开始。生产建筑可切换单个/五人批量训练；取消尚未完成的生产订单返还费用。

**H** 打开主城，XP达到门槛获得船运机会，选择卡牌发出船运。运输串行35秒，资源箱需工人采集，单位抵达需人口与出口空间。卡组编辑在主菜单中进行。

右键敌人攻击；**A** 后点地面攻击移动。**Shift + 右键** 排队命令，**Ctrl / Command + 数字** 保存编组、数字召回。**G** 后点已完工己方建筑驻军，选建筑点击 **UNGARRISON** 撤出。城镇中心中的村民可提供火力；驻军期间不采集资源。

**V** 定位空闲村民，**M** 依次选择并定位单个军队单位，包括探索者；它不会一次选中全部军队。框选作战单位后按 **J** 原地守卫，可防止待命部队追击过远。方向键或屏幕边缘移动镜头，滚轮缩放，小地图可定位与下令。探索者可探索迷雾、与守卫交战并领取宝藏；贸易站必须在地图插槽建设，完工后按设定类型获得商队收益。

升时代和持续补兵需要扩大采集人数，但早期连续排村民会延后升级。海岸经济卡组可先以约12名工人进II，之后按资源和战况增员；河谷村民花钱币，另需给银行和步兵留预算。一个资源点最多8名有效采集工，更多工人分到另一处资源。遭遇袭击时可临时驻军，清理后及时恢复采集；城镇中心最多10名村民提供火力。炮兵需长枪兵等反骑兵单位护卫，单炮容易被骑兵贴身击杀。

**Esc** 关闭面板或暂停。正常玩家局失焦自动暂停，回来后手动恢复。暂停菜单独立切换环境声、音乐及全部音频。目前没有存档；重开或退出会结束当前局。

## 海岸经济卡组的开局参考

以下路线已在同版普通Easy镜像局实际完成III、付费造炮与炮击敌建筑；该局最终自然战败，所以它是操作参考，不是获胜保证。

1. 选海岸、Economy25。收起始食物/木材箱，付费训练3名村民、建1座庄园，并用探索者处理附近木材与守卫/XP宝藏。第一张船运选2名村民，配合庄园赠工达到约12人。
2. 约8人分两处采鹿、4人采矿，资源达到800F后升II，选择食物奖励。时代奖励箱也需村民实际采集。
3. II发送600C钱币船，收箱。建200W军营，先训练少量火枪兵并按J守住采集点；保留1200F1000C给III，避免把时代款先花进连续生产队列。
4. III研究期间继续采足250C，完成后收200W奖励。4名村民建300W铸炮厂，再支付100W250C训练一门炮；等待45秒及实际出生，并留足4人口。
5. 有下一张机会时可送4名骑兵护卫。军队到港后及时按J或给移动命令，避免自由追击。M选中移动中的单位后先J停下，再框选或双击同类，会更容易控制。
6. 侦察安全侧路并护送火炮。右键地面是移动，到位后要右键**实际可见的敌建筑**攻击；炮兵射程4–20，需避免敌骑兵贴身。建筑、部队和资源压力变化时调整编组与经济。

河谷的银行、钱币村民及卡组不同，不直接套用海岸的赠工和首船。五时代路线以实际资源、人口和存活部队为准；更多规则说明见[河谷操作参考](Evidence/055/PlayerPlan/River-native-guide.md)。

## 本轮改进与证据

驻军人数变化会即时更新撤出按钮，并保留长按操作的对象保护。人物、骑兵、炮兵、11类建筑与三种资源箱采用统一原创低多边形表现；炮兵后座、骑乘姿态和生成网格销毁有针对性回归。新增原创环境风声、音乐与六种通知音色，分别处理暂停、静音和换局。

**F9** 保存当前帧及对应状态回执。**F10** 可保存最长20秒的实际游戏混音，**F8** 可保存最长10分钟的逐帧/内存样本；这些观察工具不会改变资源、AI或模拟速度。普通玩家对局、自动AI对局和压力夹具的记录分别标明，不互相代替。

本轮全量测试、客户端完整对局、音频与性能的最终数字将随验收写入 [Verification-055.md](Verification-055.md) 和同版本证据目录。现有0.2.30包保留为历史基线，不能当成新客户端结果。
