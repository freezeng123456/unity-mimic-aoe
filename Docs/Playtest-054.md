# 烽岸纪元 · 0.2.30

这是 `freezeng123456/unity-mimic-aoe` 的可试玩开发版本，保留独立项目规则。当前交付为 Apple silicon Mac 客户端；完整陆战及最终视听验收仍未完成。

## 文件与启动

- `Frontier-Reckoning-0.2.30-macOS-arm64.zip`：解压后双击 `Frontier Reckoning.app`。在菜单选择文明、时代上限、AI 难度与卡组，点击 **BEGIN SKIRMISH**。
- `Frontier-Reckoning-0.2.30-Unity-Source.zip`：源码和封存验证证据。通过 Unity Hub 用 **6000.6.3f1** 打开解压后的工程；场景为 `Assets/Frontier/Scenes/FrontierSkirmish.unity`。
- `manifest.json`：提交、构建身份、包大小与 SHA-256。客户端为 macOS arm64 / Development / Mono；尚未完成跨机器签名、公证和安装验收。

## 基本操作

框选村民，右键食物箱或浆果开始采集。开局箱子需要村民实际采集；食物、木材和钱币各自承担升级、建设与生产费用。

按 **T** 选择城镇中心并训练村民；选中城镇中心后右键资源，可设置新村民的采集集结点。按 **B** 打开建设菜单，先选建筑，再点击地图放置。海岸文明的庄园完工会提供人口上限并赠送一名村民。

按 **H** 打开主城，取得船运机会后主动发送卡牌；运输需35秒，资源卡抵达后仍需采集。时代 II 需800食物，时代 III 需1200食物和1000钱币；升级还占用城镇中心的生产时间。时代 II 开放军营、马厩与塔，时代 III 开放铸炮厂。

右键敌人进行攻击，**A** 后点击地面进行攻击移动，**Shift + 右键** 排队下令。**G** 后点击已完工的己方建筑可驻扎；驻扎村民能给城镇中心提供火力。**V** 定位空闲村民，**M** 定位军队，方向键移动镜头，**Esc** 关闭面板或暂停。正常玩家局失焦会自动暂停，返回后按 Esc 恢复。当前版本没有存档，重开或关闭会结束当前局。

## 本轮结果与边界

修复了资源耗尽后村民转向未完工农田/钱币庄园，以及按住取消按钮时生产完成导致错误取消后继订单的问题。完整 Unity 测试 **194/194 EditMode、181/181 PlayMode** 通过，验证工具 **8/8** 通过。

同一构建的3局正常规则双 AI 对局自然结束，覆盖后期时代与真实炮兵建筑伤害。正常1倍速玩家操作两局自然败北；第二局实际完成时代 II、两次船运、付费村民训练、塔楼、修理与驻扎开火，但未完成时代 III、付费军事生产和炮兵主动攻城。自动局不替代玩家路径验收。

Apple M3 Pro / 36 GB、2560×1440、60 FPS 限制下，50/100/200/400活动单位的单客户端短样本平均帧时间约16.7–16.8ms；400单位P95为17.00ms。每档仅25秒，不是长期稳定性或4K60证明。

完整证据见源码中的 `Docs/Iteration-054.md`、`Docs/Native-Verification-054.md`、`Docs/Normal-Player-054.md`、`Docs/Performance-054.md` 和 `Docs/Evidence/054`。后续验收重点为正常玩家时代 III 与主动炮兵攻城、第二文明及 IV–V、完整输入矩阵、长期性能和最终视听。
