# 四国发展练习详细操作

从主菜单 CLASSIC CIVILIZATIONS 进入，选择英国、荷兰、法国或奥斯曼

下列价格和数值均为本项目规则，界面显示紧凑操作提示，本页保留详细说明

## 英国：庄园与长弓

1. **付费完成庄园**: 选工人建造住宅 Manor；英国需135木材，完成后自动招来一名村民；不要取消施工

2. **等候庄园村民实际出生**: 庄园完工后留出人口和出口，等它实际招来村民；初始工人和城镇训练不计入

3. **付费升至时代 2**: 分配工人采集食物和钱币；选城镇中心，选择本国时代路线，付费并等待升级完成

4. **付费完成兵营**: 工人付费建兵营；长弓消耗食物和木材，留木材扩住房，新增村民继续采集

5. **付费募出4名长弓**: 选兵营训练4名 Longbowman 并等待实际出生；长弓射程长，适合在前排后持续射击

6. **付费升至时代 3**: 分配工人采集食物和钱币；选城镇中心，选择本国时代路线，付费并等待升级完成

7. **付费完成老兵长弓**: 选兵营研究 Veteran Longbowman；已生产的长弓也会获得提升

8. **侦察并实战使用特色部队**: 用探路者先侦察地图另一端的敌方探路者，再选自己付费训练的长弓右键指定攻击；累计造成30伤害；保持距离，别冲入敌城镇火力

## 荷兰：银行与轻骑兵

1. **用钱币付费训练1名村民**: 选城镇中心训练村民；荷兰支付钱币，别耗尽后续升时代所需储备；实际出生才计入

2. **付费升至时代 2**: 分配工人采集食物和钱币；选城镇中心，选择本国时代路线，付费并等待升级完成

3. **付费完成银行**: 安排工人采集食物和木材；银行需350食物与350木材；选工人建 Bank 并等完工

4. **让银行实际赚取50钱币**: 银行不占采集工人，完工后自动产币；等本次付费银行实际产生50钱币

5. **付费完成马厩**: 付费建 Stable，继续采集食物与钱币，同时留人口给骑兵

6. **付费升至时代 3**: 分配工人采集食物和钱币；选城镇中心，选择本国时代路线，付费并等待升级完成

7. **付费募出3名 Ruyter**: 选马厩训练3名 Ruyter；每名占1人口，远程反骑兵，近身较脆弱

8. **付费完成老兵 Ruyter**: 选马厩研究 Veteran Ruyter，等待研究实际完成

9. **侦察并实战使用特色部队**: 先侦察地图另一端的原有敌方探路者，再选付费 Ruyter 右键指定攻击并累计造成30伤害；保持射程，不用它们硬顶敌城镇

## 法国：猎民与胸甲骑兵

1. **付费训练1名猎民**: 选城镇中心花120食物训练 Coureur des Bois；法国开局也是猎民，新募单位实际出生才计入

2. **用新募猎民实际采集120资源**: 选本次付费训练的猎民，右键食物、树林或矿；其真实采集累计120资源；效率比普通村民高，但造价也更高

3. **付费升至时代 2**: 分配工人采集食物和钱币；选城镇中心，选择本国时代路线，付费并等待升级完成

4. **付费完成马厩**: 选工人建 Stable；胸甲骑兵每名要150食物、150钱币、3人口；提前扩住房与采矿

5. **付费升至时代 3**: 分配工人采集食物和钱币；选城镇中心，选择本国时代路线，付费并等待升级完成

6. **付费募出2名胸甲骑兵**: 选马厩生产2名 Cuirassier；队列完成后才计入；其近战范围伤害适合对付密集步兵，避开长枪阵

7. **付费完成老兵胸甲骑兵**: 选马厩研究 Veteran Cuirassier；这笔升级同时影响已有与今后生产的胸甲骑兵

8. **侦察并实战使用特色部队**: 先用探路者侦察敌方原有探路者，再让付费胸甲骑兵右键指定攻击并累计造成30伤害；发挥机动，别误冲进敌城镇火力

## 奥斯曼：自动招工与步炮协同

1. **等候自动村民实际出生**: 保持城镇中心队列空闲、人口与出口畅通；等待正常自动招工完成；自动招工是本国规则，不需要点击训练

2. **付费完成清真寺**: 选工人花100木材建 Mosque；建筑本身不提高招工速度，仍需付费研究

3. **付费改进自动招工速度**: 选 Mosque 研究 Millet System，花75木材并等实际完成；继续扩住房，自动村民才有空间出生

4. **付费升至时代 2**: 分配工人采集食物和钱币；选城镇中心，选择本国时代路线，付费并等待升级完成

5. **付费完成兵营**: 选工人建 Barracks；禁卫军可保护后排，近战对骑兵有加成

6. **付费募出3名禁卫军**: 选兵营训练3名 Janissary 并等实际出生；分配食物与采矿工人供给军队

7. **付费完成铸炮厂**: 选工人建 Foundry；奥斯曼时代 II 就能使用它训练 Abus Gunner

8. **付费募出2名 Abus**: 选铸炮厂训练2名 Abus Gunner；它们占2人口，射程较长，别让它们单独接敌

9. **侦察并实战使用特色部队**: 先侦察原有敌方探路者，再分别选禁卫军和 Abus 右键指定攻击；两类付费部队各需实际造成30伤害；禁卫军在前，Abus 在后，避开敌城镇
