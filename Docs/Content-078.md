# 078 · 蜿蜒河谷接水边缘精修

本轮继续四部分河图计划的第一部分，处理077画面中外弯接水线的细小三角咬边。0.21.0 是新候选版本；旧076／077构建、原图、证据和发布保持原身份，四部分尚未整体完成。

## 已接入的内容

- 先用实际水条边界与原地表三角形测量原因：3010条有效采样记录中，原1m网格有54条遮水超过2mm；这些记录含共享端点，不等于54处独立缺口。
- 仅将普通非场景Winding地表从1m／129²细化到0.5m／257²，沿用同一高度、分层颜色、UV、材质查询和固定三角形对角线。相同有效样本的超阈值遮水54→0，东外弯18→0。
- 水面、权威陆水查询、仿真、导航、桥梁、港址与其他地图密度保持原合同；未新增Collider。三角形数量增至4倍，性能影响另验，不称为零成本优化。
- 普通26与近景16的实际URP同位对照可见三角咬边减少，仍保留有限折线、泡沫与抗锯齿；重建粗地形诊断图不是旧版本原生截图。
