# 083 · 河口潮岸首段（0.25.0 Candidate2）

这一段精修已有的 River Estuary：北部连续低泥沙滩与干草肩、西岸 `(41,92)` / 东岸 `(72,92)` 两个明确登陆点。沿用已完成的码头、渔船和战船轮廓，保留两桥、北桥贸易、六个鱼点、六矿、62树和既有 AI 模式。

岸高与泥沙层消费同一个河口权重；沿河中心渐变，避开开局、旧港/生产出口、桥坡、贸易线和新登陆点。水床、水域、导航和一米网格保持原合同。这是静态潮岸形态，未实现涨退潮或潮流改速。

两处登陆点先经过实际调查，再接入普通双人地图。两玩家、原北港存在时，最大炮兵 `great_bombard` 均能准确卸载，分别连接原矿木和贸易节点。对应调查是独立摆设的几何/公共命令验证；不能据此宣称河口普通经济付费全链已完成。

当前已实际通过五个内容/地形用例、真实 URP 四视角/重复帧与索引水线探测。完整回归、最终构建和新云盘包以 [083验收](Verification-083.md) 的最新状态为准。

本段与 082 调度修正在同一 Candidate2 中交付，应用版本仍为 0.25.0。后续可继续扩展河口作业地标、普通付费渔业/运输链和 AI 水陆投资选择。
