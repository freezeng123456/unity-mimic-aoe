# 发射时目标校验契约 · 033

此规则先于本轮测试与实现冻结。它是 **P：本项目战斗时间模型**，不宣称是已核实的《帝国时代 III：决定版》弹道细节。原作炮兵最小射程及目标在攻击准备中跨越边界时的精确行为仍属于 `Reference-Combat-Shipments.md` 的 REF-COMBAT-004 待核实范围。

当前炮兵配置最小射程为 4，部署两秒后才可准备攻击。032 场景验证覆盖从输入到建筑命中，但没有覆盖目标在准备期间进入最小射程。代码只在开始准备时检查最小射程，实际发射处仅检查最大射程；这需要最小复现确认，不能仅凭静态阅读声称已验证修复。

本项目在发射时再次检查：目标仍存活、可观察、未驻扎、武器仍有火力，且目标边缘距离不小于配置最小射程。最小射程边界本身允许射击。最大射程继续使用已有的发射容差，不在本次改动中重新平衡。

目标在准备与发射之间进入死角时，取消这一发，不创建弹丸、不发出 Fire/Impact、不造成该发伤害；已经开始的装填期限保留。目标重新进入合法射程后，需要等原攻击间隔结束，再完成正常部署或准备，不允许反复取消来重置冷却。

已经发出的弹丸沿用已有目标追踪和命中规则；目标在飞行中靠近炮口不撤销已发射弹丸。目标在发射前死亡、失去视野或进入驻扎时取消发射；目标在发射后死亡时丢弃对该死亡目标的命中，不转换成凭空范围伤害。

验证必须采用当前炮兵定义与真实 `World`/固定时间步进，先在旧运行时观察失败，再使用同一测试文件验证修复。夹具可以隔离周围单位、设置目标位置或移动命令来控制边界，但不能关闭部署、最小射程或装填以便通过。记录自动规则测试、场景测试、客户端检查各自范围；不能由此替代正常开局的玩家攻城或完整阶段验收。
