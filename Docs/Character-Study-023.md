# 0.2.3 原创单位装备与动作检查

本项属于阶段 C 开发中的局部表现改进，所有新增网格与动作代码由本项目制作。没有引入商业游戏素材，也不是最终人物美术交付。

此前 0.2.2 的长弓兵、军刀骑兵和枪械骑兵共用长条枪械外形，双臂没有肘、手和武器链。0.2.3 增加肩—肘—手的两段刚性手臂、武器挂点和恢复初始姿态的缓存。火枪/骑枪具有枪托与枪管，长枪具有枪头，长弓使用弧形网格及两段弦，军刀骑兵使用刀刃与护手。炮管/车轮、马四腿具有各自转轴。仍是程序化灰盒人物，骑手身体、马体和建筑尚未达到最终美术标准。

姿态只读取模拟状态和真实事件时间，不扣血、不推进攻击或经济。实际位移驱动行走，已经到达采集/施工/修理位置的工作状态驱动挥工具。准备、发射、装填依据 fireAt/attackReadyAt/Fire 时间读取；枪械持握、长枪平刺和弓弦通过真实手部坐标形成。伤害事件现在记录受击目标位置，开火事件保存当时朝向。死亡倾倒保留 0.7 模拟秒，随后回收；复用恢复姿态与事件时间，暂停使用同一模拟时间。当前动作是项目表现规则，不声称与原作动画、比例或时长一致。

## 实际检查与修正

使用 Unity 6000.6.0f1 的 URP SingleCameraRequest 与 RenderTexture 渲染检查图；基线来自本项目冻结的 0.2.2 源码包，只改类名/命名空间后置于测试程序集，不进入客户端。两版使用相同正交相机、灯光和排列，另有保留几何/法线的中性材质图。每种武器的 idle、prepare、fire、recover 使用独立实体和明确时间采样，未用同一实例覆盖图片。

第一轮检查确实暴露长枪上举方向错误、火枪左手离开枪身、弓弦不跟手、标签遮挡和首帧材质未稳定的问题。第二轮修改为两段手臂解算、模型空间武器方向、弓弦端点跟随实际右手，修正相机宽高比和标签尺寸，并增加渲染预热。root 已实际查看两轮 PNG：第二轮长枪沿前方平刺，枪械双手持握，弓弦具有拉伸变化。检查图明确是 Unity 离屏动作诊断，不是玩家操作截图或完整游戏画面验收。

自动测试直接实例化 ProceduralArt 的真实模型，检查武器挂在手部、枪管/长枪实际轴方向、100 次重复姿态不累积、Idle→Prepare 恢复一致，弦两段端点与真实右手及弓臂端点重合。另有真实 WorldView 开火朝向、暂停、死亡停留、回收复用和重新开始测试。

## 仍未完成

没有蒙皮、完整人体/骑乘动画、脚步与地面同步、按资源类型换工具、箭矢搭弦、最终装填细节或最终死亡演出。当前静止持弓仍偏低，骑手腿与马体的造型/坐姿需要重做，炮兵缺少操作手。原生游戏镜头下的武器识别度、拥挤遮挡、连续动画过渡、整局帧时间和听感仍未验收。以上 PNG 通过不能改变这些边界。

中性材质、骑兵军刀与炮管的第二轮输出也已逐张查看：军刀在当前尺度偏细、骑乘腿仍为占位造型，炮兵仅完成炮管后坐与轮轴运动，没有操作手。它们不列为视觉质量通过。后续进入原创人体/马体网格替换时，先保留本轮动作及空间断言，再做同机位对比与真实游戏镜头验收。
