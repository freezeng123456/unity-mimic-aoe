## 行为约定

1. 正常玩家单机局处于运行状态时失去应用焦点，立即停止模拟时间并打开暂停面板，明确显示因为离开游戏窗口而暂停。返回窗口保持暂停，只有 RESUME、ESC 或暂停面板关闭按钮主动恢复。
2. 暂停调用现有声音暂停逻辑，释放鼠标限制。清除未完成的框选、按键/指针事件、旧 UI 按压捕获、待放置建筑、攻击/驻扎目标模式；保留已有选择、编队与已经接收的模拟指令。
3. 时代/主城/建造面板被暂停面板替换，不代为选择、付款或发送。恢复后玩家可重新打开。已经入队的生产、船运、采集和攻击冷却随模拟时间冻结，恢复不追补后台时间。
4. 重复失焦幂等；已手动暂停的局不切成运行状态，也不伪称为失焦暂停。菜单、已结算局、自动对战与性能诊断不触发该单机策略。批处理测试的应用回调不干扰测试运行。
5. 暂停面板 X 与 RESUME 同义，不能只隐藏面板却留下冻结的世界。重开、返回主菜单和新局清理暂停来源及输入状态。
6. 报告事件记录真正发生的暂停/恢复转换和原因，时间戳使用模拟时间。诊断日志可补充实际墙钟相对时间；不能用事件数、模拟时间或渲染帧差伪造后台停留时长。
