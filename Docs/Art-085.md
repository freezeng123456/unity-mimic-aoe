# 085 · 四国兵种与河谷美术

本轮优先改善常用战略镜头下的兵种辨识、港区结构与地表层次

## 已实现

- 英国长弓手增加浅木弓、箭囊和深色帽，长枪兵采用钢盔、胸甲和肩甲，前后排轮廓更清楚
- 荷兰Ruyter使用宽沿帽、浅革甲、短骑枪和轻鞍布，实际单位ID为carabineer
- 法国胸甲骑兵强化金属胸背甲、盔冠和重鞍布，保留原骑乘与持剑动作
- 奥斯曼禁卫军采用高白帽和队色长袍，Abus采用圆缠头、青铜粗管和凹入暗膛
- 城镇中心扩大窗墙分区、重做门廊，兵营增加清楚的主入口，屋顶增加宽檐与阴影层次
- 港仓改为灰绿坡顶、深色屋脊和梁架、浅墙深窗，栈桥增加连续侧梁
- 护卫舰区分炮门和双站帆装，运输船增加低三角帆与开放货舱框，渔船采用低折篷
- 原创草地贴图混合两种尺度，降低饱和度与碎纹对比，岸边部分草石簇改为低矮灌丛
- 河水保留原反射法线与高光，增加克制的流纹色差，回退实拍中过亮的长光带

单位动作关节、阵营色、建筑占地、港位与水域边界沿用原规则
