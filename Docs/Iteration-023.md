# 0.2.3 开发检查点与实际证据

当前为阶段 C 开发，局部阶段 D 表现改进；不满足完整陆战或阶段 D 完成标准。继续完整 A—D 目标，不把后台自动对局、代码、编译、测试或动作检查图等同游戏完成。

## 改动

AI 增加持续时代计划：进入后少量战损不释放升级储备，严重可见入侵时暂缓并恢复防守，安全间隔后恢复，长期无进展会退出。计划只控制正常指令和已拥有资源，没有增加免费收入、透视或出生单位。开局/单位/建筑/卡牌数值保持与0.2.2相同。合同见 AI-Age-Plan-023.md。

人物增加肩肘手与真实武器链，区分长枪、弓、军刀、火枪/骑枪，炮管/车轮和马腿有独立转轴。姿态读取实际工作状态、攻击准备/发射/装填计时与受击/死亡事件。暂停冻结动作，回收后复用恢复姿态。伤害事件记录受击位置，开火事件保存当时朝向。第一轮 Unity 离屏图发现的持握、武器方向与弓弦错误已修正，仍是灰盒研究。详见 Character-Study-023.md。
