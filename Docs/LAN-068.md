两个人类席位为房主 P1、客户端 P3，同队；P2/P4 的 AI 只在房主运行。支持手动地址/端口、同一客户端发行构建、文明和牌组 READY、大厅地图/种子/难度/时代上限/目标设置。客户端没有模拟调度器或录像记录器。控制身份使用 LocalPlayerSlot，观察身份使用 ObserverPlayer；LAN 锁定自己的观察席位，录像继续允许切换视角。

房主和客户端输入都进入同一个权威提交队列。初始及每一步前的边界按 hostSequence 排序，回执含实际 completedStep、ordinal 和 stateRevision。共享暂停由房主录像记录；暂停时仍泵送 Resume、心跳和回执。本地 Esc/失焦仅关闭本地输入与打开菜单，房主世界可继续推进。客户端等待终态及对应状态才显示结果。

请求以 match/epoch/peer/sequence 去重；换连接 generation 不换逻辑请求。已接受、已拒绝与待处理结果均保留；终态窗口每 peer 1024，淘汰后的旧编号拒绝。未确认请求按编号排序重传。断连后等待完整状态才恢复下令，保留本地菜单；最后显示世界不自建 AI 续局。1 秒心跳、5 秒断线、30 秒重连宽限为当前默认值，宽限到期房主通过同队列提交远端投降。显式离开会关闭该席位的恢复资格；退役后不会再显示仍可重连。连接、自己的 READY、等待伙伴、双方 READY 与开局同步分别显示对应状态。

生产取消使用网络专用稳定任务 ID。即使两条完全相同的训练任务相邻、队列头刚完工或任务下标变动，房主只取消被点击的那个未完成任务；已完成任务拒绝，不退款后继。此 ID 不改变旧生产、存档或回放格式。

复制包括玩家经济、生产/运输/船运、实体 ID、订单、路径、迷雾、导航、炮弹、中立盟友、地图目标与恢复队列，以及生产任务稳定 ID。Full 静默设置事件游标并拒绝回滚；Delta 要求正确基线及投影摘要，失败保留旧世界并请求重新同步。普通更新保留 World/玩家/既有实体对象及渲染缓存，接收基线、显示世界和待发送数据分别持有可变嵌套数据；复制不会调用 Spawn/Remove/Issue/Tick 产生第二笔付款、XP、损失或声音。

TCP 后台线程只操作字节。帧 8 MiB、展开 JSON 32 MiB、每方向队列 128 帧/16 MiB、单命令 64 KiB、最多 1024 actors；item/choice 各限 256 个 C# 字符串字符，并验证 UTF-8，不是各限 256 字节。每 peer 最多 256 pending、房主最多 1024 pending；主线程每端每次最多消费 8 条消息。复制限 20,000 实体、每生产队列 6 个任务、每 delta 4,096 条新事件；客户端保留有限事件尾部。退出/协议错误会有界地发送完最后帧再关闭，超时后台兜底，不在 UI 线程阻塞等待。这些是实现中的限制，不是已测带宽、延迟或大军性能结论。

这是可信朋友 LAN 的完整世界投影；客户端进程可持有被雾遮挡的数据。本版范围不包含竞技防作弊、加密、公网匹配/NAT/中继、主机迁移、跨构建或跨平台互通。本机真实 TCP 自动化、同机两个原生进程、两台物理 Mac 的验收分层记录，不能相互替代。
