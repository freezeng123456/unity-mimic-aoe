# 049 / 0.2.25 · 移动、工作声音与静音修正

本轮补齐原先明确缺少的单位活动声音，并修正暂停中关声音后，恢复对局可能续播旧尾音的问题。保持快速、小步迭代与关闭实时阴影。用户旧版0.2.21游戏保留，未启动新版替换；完整阶段D仍未完成。

## 实际行为与声音联动

新增村民最近一次实际工作记录 WorkActivity（动作、目标、资源种类、模拟时间），保存在实体运行时状态。采集在正收入入账后记录；施工在工人到达且计入当步有效施工者后记录；修理在实际付费并增加生命后记录。它不授予资源、不加快生产、不改变经验或伤害，不写入共享Rules。仅接受订单、未完工设施、等待工作位或缺钱修理不会产生新的工作记录。

UnitActivityAudio每个新模拟时间只观察一次，消费当前步工作记录；移动依据真实position/previousPosition位移，按步距累计，排除原地与异常大位移。步距为普通单位1.4、骑兵2.2、炮兵1.8世界单位；工作资格间隔0.8模拟秒。活动声只来自活着、未驻扎、当前可见、中心点位于屏幕内的单位；后来揭雾不补播同一旧步。停止后不生成新脚步，失去视野、离屏、暂停、静音、结算与重开清理活动状态。

新增七类原创短合成音：Footstep、Hoof、Wheel、Woodcut、Mine、Handling、Build，修理复用Build。所有声音通过Unity原生AudioSource播放，活动声依屏幕横向位置设置左右声道。仍是二维混音，不是声学传播、遮挡或真实空间音频；步声也不是逐脚掌接触的最终动画事件。节奏、声道与音色属于项目P视听参数，未冒称原作数值。

固定12声道重新分配为8战斗、2活动、2战略通知。活动每0.085真实秒至多一个新短音，不占用战斗/通知槽；每次只选择一个当前最优活动源，已选单位优先、其次屏幕中心附近。快进/低帧率时不补播积压声音，密集单位中的部分声音会被省略。该取舍及边缘截断听感仍需原生混音验收。

Muted由仅阻止新事件改为立即Stop并mute全部已有声道；暂停恢复尊重静音，解除静音不恢复旧尾音。UI入口仍是暂停面板SOUND ON/OFF。

## 复现、测试与音频样本

五项行为用例先在旧运行时运行，再冻结文件哈希：旧版0/5通过、新版5/5通过。它们通过真实World.Issue、World.Tick和GameController.Update派发验证移动、资源收入、付费施工、修理、停止、未完工采集、缺钱、雾后/离屏/暂停活动及静音重开。测试用受控资源/单位和直接设置的测试库存；手动推进World，设置Autoplay=true、SimulationSpeed=0以避免控制器额外推进。不能称普通玩家对局。

最初两项负例把附近守卫的合法脚步与近战算成村民仍发声。诊断日志确认actor118/119，并未发现村民的假工作声。隔离守卫后**重新运行旧版红例**再运行新版绿例；最终红绿为同一个隔离后的文件。初版结果及诊断保留，不用改过的测试冒称同一红绿链。所有临时DEBUG-audio049源码日志已去除。

新增覆盖另行验证马蹄/车轮、矿石/食物/箱子路由、八名采集者的两活动槽上限、战斗与通知槽可用，以及音频派发不改变资源余额或模拟事件。全量 **EditMode164/164、PlayMode171/171** 通过。

Editor/AudioAudit从与客户端相同的合成模块生成七个AudioClip，检查有限样本、时长、声道、采样率、峰值与首尾，并导出PCM16 WAV。采样率22050Hz单声道，时长约0.085–0.27秒，最大实测峰值约0.320（未乘活动声道0.1音量），首尾均为0。包络统一使用2ms attack/20ms release与衰减，避免归一化时间/秒混用。**样本数学检查与Play调用计数不是耳听验收，也不是最终音效品质证明。** 参数见 [Audio-Design-049.md](Audio-Design-049.md)，样本及原始指标见 [Evidence/049/audio-clips](Evidence/049/audio-clips)。
