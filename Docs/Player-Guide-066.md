# 0.9 玩家指南（066）

本指南对应当前 `0.9.0` 的按钮和默认按键。玩法范围及规则说明见 [内容说明](Content-066.md)。界面中的课程和战役说明为中文，多数通用按钮仍使用英文。

## 第一次进入

想先学操作，在主菜单点击 `GUIDED LESSONS`，选择“1. 选取与移动”。用 `NEXT` / `PREVIOUS` 翻阅课程列表；七课都可直接进入，不必先完成前一课。

进入场景后先看当前目标。`MISSION BRIEFING` 打开任务说明和清单，`FIND OBJECTIVE` 或说明中的 `LOCATE` 将镜头移至目标。标记不会替你选人或下令，仍需在地图中操作。按当前清单顺序完成目标，等待它显示 `[DONE]` 后再做下一步。

需要停止世界推进时，按 `Escape` 并确认出现 `MATCH PAUSED`；点击 `RESUME` 继续。若当前正在放建筑、选攻击点或打开窗口，`Escape` 会先取消该动作或关闭窗口，再次按键才进入暂停。普通对局失去窗口焦点也会暂停，回到游戏后从暂停菜单恢复。

## 选人、下令与镜头

- 左键选择单位或建筑，拖动左键框选己方单位；Shift 可追加选择。双击己方单位可选附近同类单位。
- 选中单位后，右键地面移动；村民右键资源开始采集；右键敌人发出指定攻击。选中己方生产建筑后右键地图设置集结点。
- `A` 进入攻击移动模式，再左键地图指定目的地；`J` 原地守卫，`S` 停止当前命令。任务要求“指定攻击”时，直接右键指定敌方目标。
- 进入建造或选目标模式后，左键确认位置或对象；右键取消该模式。Shift 可用于追加支持排队的命令或施工。
- 方向键移动镜头，鼠标滚轮缩放，`F` 聚焦所选对象。点击小地图移动观察位置；战争迷雾仍限制敌军显示。
- Ctrl 或 Command 加数字 0–9 保存当前己方选择为编组；按相应数字召回该编组并聚焦。

选中盟友或敌方对象可以查看 `DETAILS`，玩家只能指挥第 1 槽的单位和建筑。

## 七课怎么完成

| 课程 | 操作路径 |
| --- | --- |
| 1. 选取与移动 | 单击提示的探路者，再右键标记，等人走到目的地 |
| 2. 采集与建造 | 村民右键树木，等累计新采集 75 木材；选村民按 `B`，点击住宅并在空地左键放置，等施工完成 |
| 3. 升时代与募兵 | 按 `T` 选城镇中心，点击 `ADVANCE AGE` 并选择路线，等时代 II 完成；村民建完兵营后，选兵营点击火枪兵招募，等 2 人实际出生 |
| 4. 家乡船运 | 按 `H` 打开家乡牌组，发送当前时代可用卡牌；关闭窗口继续模拟，等这次船运真正抵达 |
| 5. 指定目标攻击 | 选长枪兵右键指定骑兵，等击杀；再右键指定仓房，等建筑被摧毁 |
| 6. 中立盟友 | 指定探路者右键聚落旁标记并抵达；村民在聚落贸易插槽建完贸易站；点击插槽或贸易站的 `SETTLEMENT`，保持附近陆军接触，依次付费 `NEGOTIATE` 和 `RECRUIT`，分别等条约完成、盟军出现 |
| 7. 运输与登陆 | 选两名提示士兵，右键己方运输舰并等其实际登船；选船点击 `UNLOAD` 或按 `U`，左键目标岛岸，等两人卸载；选登陆士兵按 `J` 守卫标记区域 |

资金不足、时代不符或条件未满足时，以按钮提示和命令反馈为准。第 3、4、6 课有说明中明示的教学资源或经验；升级、建设、募兵及条约仍使用真实支付与完成流程。生产排队、船只正在靠岸或卡牌显示 `IN TRANSIT` 时，还需要继续等待。

课程中双方普通 AI 关闭，目标由固定场景提供。每课限时 20 分钟模拟时间。必要探路者、运输舰或任务部队损失，城镇中心失守，超时以及破坏指定攻击顺序等情况，会触发失败。

## 原创河流战役

主菜单点击 `RIVER CAMPAIGN`。第一章可以直接进入；完成第一章并保存进度后解锁第二章，再完成第二章解锁第三章。每章限时 30 分钟模拟时间，下一章从自己的固定开局开始，不带入前章军队和资源。

1. **河谷补给线：** 先实际采集 100 木材，付费完成住宅、兵营及 4 名火枪兵。防守阶段骑兵开始突袭；用指定攻击或攻击移动迎战，击退两名骑兵并保住城镇中心。
2. **桥头通路：** 选前线士兵，右键桥东标记或用 `A` 指向该位置，等至少两人越桥到达；随后右键指定仓房并摧毁它。
3. **河口登陆：** 选提示的六名士兵，右键运输舰，等至少四人登船；选船卸载到标记岛岸，等至少四人实际登陆；登陆部队右键指定仓房并摧毁它。

战役使用受控场景和真实命令。第一章有脚本发起的骑兵突袭，没有敌方经济发展 AI；后两章关闭普通 AI。按说明中的指定目标操作，单纯自动攻击或提前摧毁后续目标可能无法满足当前阶段。

完成后显示 `CHALLENGE COMPLETED`，自动尝试保存本地完成记录；失败显示 `CHALLENGE FAILED`。`RETRY` 重新开始该场景，`NEXT` 进入已解锁的后续场景，`MAIN MENU` 返回主菜单。遇到完成记录保存错误，可在完成窗口点击 `SAVE PROGRESS` 再试；失败尝试不会解锁下一章。

## 开一局自由对战

在主菜单选择 `YOU` 文明、`AI DIFFICULTY`、`MAP`、`ERA LIMIT` 和牌组 `PRESET`；`EDIT DECK` 调整玩家牌组。`MAP, SEED & OBJECTIVES` 可以查看地图、种子及地图目标。

点击模式按钮切换 `1 VS 1 DUEL`、`2 VS 2 TEAMS` 或 `4 PLAYER FREE FOR ALL`，在 `LOCAL PLAYERS & TEAMS` 中点击各槽按钮选择文明，再点 `DONE`。最后点击 `BEGIN SKIRMISH` 开局。

| 选择 | 你和谁作战 |
| --- | --- |
| 1v1 | 第 1 槽玩家对第 2 槽 AI |
| 2v2 | 你与第 3 槽盟友 AI，对抗第 2、4 槽 AI |
| 四人自由混战 | 你与三个 AI 各自为战 |

这三种模式都是本地单人操作加 AI。盟友与你共享视野，但资源、人口、生产、牌组和军队控制独立。2v2 中即使你被淘汰，只要盟友仍在，对局还可以继续；最终结算按队伍胜负显示。暂停菜单的 `RESIGN` 只让你的槽位投降。

基本发展可从城镇中心生产村民、派村民采集资源开始。选村民按 `B` 打开建造菜单，选建筑后在当前视野中的合法空地放置；选城镇中心的 `ADVANCE AGE` 选择下一时代路线；选已完成兵营等建筑招募单位。等待支付后的施工、时代和生产完成，再使用新能力。船运通过 `H` 请求，实际到达后按卡牌内容获得单位、资源实体或效果。

## 默认快捷键与改键

以下 20 个动作可以在 `SETTINGS` → `HOTKEYS` 改绑；按钮括号中的快捷键随绑定更新。

| 动作 | 默认按键 | 用法 |
| --- | --- | --- |
| 攻击移动 | `A` | 进入选点模式，再左键目的地 |
| 停止 | `S` | 停止所选单位命令 |
| 原地守卫 | `J` | 守住当前位置，不追击 |
| 驻防 | `G` | 选择可容纳己方单位的建筑 |
| 修理 | `R` | 选择相应可修理的受损对象 |
| 家乡牌组 | `H` | 打开船运卡牌 |
| 建造菜单 | `B` | 选村民后打开建筑选项 |
| 闲置村民 | `V` | 选择闲置村民；默认绑定时 `.` 也可用 |
| 城镇中心 | `T` | 选择己方城镇中心 |
| 军队 | `M` | 选择己方军队 |
| 聚焦选择 | `F` | 镜头移至选择 |
| 登船 | `E` | 选择士兵后进入运输舰选目标模式 |
| 卸载 | `U` | 选择有乘员的运输舰后进入岸边选点模式 |
| 港口修船 | `K` | 选船后左键己方已完成港口，靠泊并付费修理 |
| 镜头向左 | `←` | 移动镜头 |
| 镜头向右 | `→` | 移动镜头 |
| 镜头向上 | `↑` | 移动镜头 |
| 镜头向下 | `↓` | 移动镜头 |
| 放大 | `=`，界面显示 `+` | 放大镜头 |
| 缩小 | `-` | 缩小镜头 |

`HOTKEYS` 分页显示动作。点击要改的动作，按一个未使用且未保留的键；成功后立即保存。键冲突不会自动交换，重新点击该动作后再选键。闲置村民改绑后，旧 `V` 和 `.` 不再为该动作生效。

`Escape`、`F8`、`F9`、`F10`、`.`、`Tab`、回车、数字 0–9、空格、Shift/Ctrl/Alt/Command 修饰键、上下文菜单键及输入法专用键不能改绑。`Escape` 用于取消、关闭或暂停，数字及修饰键用于编组和追加操作，`F8` 为性能采样、`F9` 为截图与元数据捕获、`F10` 为诊断混音采集。

## 声音、文字与小地图

从主菜单或暂停菜单打开 `SETTINGS`。

- `AUDIO`：主音量控制整体，`Effects & alerts`、`Music`、`Environment` 分别控制音效提示、音乐和环境声。可以开启 `Mute all`，或单独关闭音乐、环境声。当前没有录制单位语音。
- `ACCESSIBILITY`：`UI scale` 可调 0.85–1.30；`Friend / foe markers` 加入槽位形状；`High contrast minimap` 改变小地图对比；`Event captions` 控制事件文字，`Action hints` 控制字幕栏中的操作提示，普通命令反馈和快捷键说明仍保留。
- 点击 `SAVE SETTINGS` 应用并保存音量、比例和开关；`BACK` 放弃尚未保存的这些改动。成功改键已立即保存，不受 `BACK` 撤销。

初始设置为音量 100%、音乐与环境开启、UI 比例 1.00、事件文字与操作提示开启；形状标记和高对比小地图默认关闭。静音时仍可以显示文字提示。形状与高对比设置不显示战争迷雾中的隐藏敌军。

## 保存、恢复与文件位置

手动保存正在进行的对局：按 `Escape`，点击 `SAVE MATCH`，选择 `SLOT 1`、`SLOT 2` 或 `SLOT 3`。选择已有槽位会替换该检查点。恢复时用主菜单的 `LOAD SAVED MATCH` 或暂停菜单的 `LOAD MATCH` 选槽；成功加载后仍暂停，点 `RESUME` 继续。

检查点包含世界、生产和模拟状态、镜头、选择及编组；课程/战役还保存同一次尝试的阶段和命令依据。它不会替你补做目标，也不会倒退已保存的长期完成记录。对局检查点需要同一应用版本和同一规则内容；当前是 `0.9.0`，旧版本的槽位可能显示 `REQUIRES GAME` 或读取错误。

原生应用的数据根目录由 `Application.persistentDataPath` 决定，当前 macOS 路径为：

```text
~/Library/Application Support/Frontier Workshop/Frontier Reckoning/
  Saves/slot-1.json
  Saves/slot-2.json
  Saves/slot-3.json
  Account/guided-progress.json
  Preferences/player-settings.json
```

三个 `Saves` 文件是手动检查点；`Account` 文件是完成记录和章节解锁；`Preferences` 文件是玩家设置。读取对局不会覆盖当前音量、可访问性或改键偏好。进度和设置都是本机保存，没有云同步。

如果设置加载失败，游戏使用默认偏好并保留原文件。之后显式保存或改键保存时，先把不可读原文件复制到 `player-settings.json.unreadable-<身份>`；备份失败就不会覆盖。若课程进度文件不可读，游戏保留原文件并阻止写入，当前没有界面内修复或重置入口。可退出应用、先备份数据目录，再恢复自己保留的有效文件；不要把删除损坏文件当成恢复已有完成记录。

检查点读取失败不会替换当前对局，写入失败保留原槽位；以界面显示的成功或错误反馈为准。
